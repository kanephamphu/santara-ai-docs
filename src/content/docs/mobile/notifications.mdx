The **Notifications** system on Santara AI Mobile ensures you never miss any important events.

## 1. Identifying Notifications

You can always see the **Bell** icon prominently displayed on the app's Header on almost every screen.
- When there is a new notification, the bell will be accompanied by a red number indicating the number of unread notifications.
- If you have too many unprocessed notifications, the system will automatically shorten it and display **"99+"** to avoid cluttering the interface.

## 2. Notification Center

Tap the bell icon to open the **Notification Center Modal**. Here, you can view all the latest system alerts sorted chronologically.

![Notifications Screen](/screens/en/notifications.en.png)

### Processing Notifications
Notifications are not just static text. Santara AI supports direct **Deep Linking**. This means that when you tap a notification (for example **New booking** or **Issue assigned**), the system will jump you straight to the details screen of that booking, or open the corresponding chat flow, saving maximum taps and swipes. Tap **Mark all as read** to clear the count.

## 3. What You Are Notified About

The bell holds the same sixteen kinds as the web dashboard — see
[Notifications](/setup/workspace/#notifications) for the full list:

- **Bookings** — new, changed, cancelled, and **Overbooked** (a room sold past its available units).
- **Cleaning** — a clean assigned to you, a clean finished.
- **Issues** — a ticket opened, assigned to you, in progress, or resolved.
- **Channels** — a channel connected, a channel that didn't accept an update, a sync warning.
- **Guest requests** from the guidebook, and **AI assistants** asking for approval or reporting a change.

Each one shows only to the people whose role can act on it, so a cleaner does not see booking alerts.
