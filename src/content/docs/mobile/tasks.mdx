The **Tasks** tab is where the cleaning and maintenance team checks the to-do list for today and tomorrow. This screen is divided into 3 main areas (tabs) for easy management:

## 1. Cleans

Based on the guest arrival/departure schedule, the system will automatically generate Turnover Tasks before the checkout date.
In the Cleans tab, you will see a list of rooms that need cleaning, checkout times, next arrivals, and assigned staff.

Each Task card clearly displays which room and which property it belongs to, and has these buttons:

- **Mark done** — tap it when the room is finished. The button then reads **Done · Undo**, in case you tapped it by mistake.
- **Add photo** — opens **Evidence & notes**, where you attach photos and notes as proof of the clean. Each task can have **up to 10 photos** (PNG, JPEG, WebP or GIF, 5 MB each). Photos are optional, but they settle questions later.
- **Skip cleaning task** — for managers only: use it when the clean is not needed. It reads **Skipped · Undo** afterwards.

A cleaner sees only the cleans assigned to them.

![Cleaning Task Board](/screens/en/tasks.en.png)

## 2. Issues

This tab manages maintenance issue tickets. If a guest complains or a staff member notices a blown light bulb or a broken AC, they can open an Issue right on the app.

Managers can view the list of open, in-progress issues and assign them to repairmen. Similar to cleaning rooms, the repairman will mark it as complete after fixing the issue.

![Issue and Maintenance Management](/screens/en/issues.en.png)

## 3. Default Cleaners

In this tab, managers can view and arrange the default cleaners for each room or property. Cleaners do not see this tab.
Setting up default staff helps cleaning tasks (when automatically generated) to be assigned directly to the right person in charge, saving time on manual assignment every morning.
