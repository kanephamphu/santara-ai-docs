เอกสารนี้เขียนด้วย markdown และเผยแพร่เป็น markdown ถ้าคุณอยากส่งหน้าใดหน้าหนึ่งให้ ChatGPT, Claude หรือเอเจนต์ของคุณเอง คุณไม่ต้องดึงข้อมูลจาก HTML ที่เรนเดอร์แล้วเลย

## คัดลอกหน้าเดียว

ที่ด้านบนของทุกหน้า:

- **คัดลอกหน้า** — คัดลอก markdown ของหน้านั้นไปยังคลิปบอร์ด
- **ดูเป็น markdown** — เปิดไฟล์ต้นฉบับ
- **เปิดใน ChatGPT / เปิดใน Claude** — เปิดแชตใหม่พร้อม URL ของ markdown ของหน้านั้น และคำสั่งที่เขียนไว้ให้แล้ว

## ไฟล์คู่ `.md`

URL ของหน้าใดก็ได้ที่ต่อท้ายด้วย `.md` จะได้ต้นฉบับ markdown:

```
https://docs.santara.ai/channels/airbnb/      → the page
https://docs.santara.ai/channels/airbnb.md    → the markdown
https://docs.santara.ai/id/channels/airbnb.md → the Indonesian markdown
```

ไฟล์คู่ของหน้าแรกคือ `/index.md` ทุกหน้ามี `<link rel="alternate" type="text/markdown">` ชี้ไปยังไฟล์คู่ของตัวเอง ครอว์เลอร์จึงไม่ต้องเดารูปแบบ

## คู่มือทั้งหมดในไฟล์เดียว

| ไฟล์ | คืออะไร |
| --- | --- |
| [`/th/llms.txt`](/th/llms.txt) | แผนที่: ทุกหน้า URL ของหน้า และคำอธิบายหนึ่งบรรทัด |
| [`/th/llms-full.txt`](/th/llms-full.txt) | เอกสารทั้งหมดเป็นไฟล์ markdown ไฟล์เดียว |
| `/llms.txt`, `/llms-full.txt` | แบบเดียวกัน เป็นภาษาอังกฤษ |
| `/id/llms.txt`, `/id/llms-full.txt` | แบบเดียวกัน เป็นภาษาอินโดนีเซีย |
| `/vi/llms.txt`, `/vi/llms-full.txt` | แบบเดียวกัน เป็นภาษาเวียดนาม |

ภาษาใดที่ยังแปลไม่ครบจะใช้หน้าภาษาอังกฤษแทนสำหรับหน้าที่ยังไม่ได้แปล ดังนั้น `llms.txt` ที่ไม่ใช่ภาษาอังกฤษจึงเป็นแผนที่ครบทั้งระบบเสมอ ไม่ใช่แค่บางส่วน

## ทำไมต้องใช้

หน้าเอกสารที่เรนเดอร์แล้วคือ HTML หลายร้อยกิโลไบต์ที่ห่อเนื้อหาไม่กี่กิโลไบต์ไว้ เครื่องมือตอบคำถามที่ดึง markdown จะได้ถ้อยคำเดียวกันโดยใช้ข้อมูลเพียงเศษเสี้ยว และอ้างอิงได้ถูกต้อง เพราะไม่มีเมนูนำทาง ไม่มีแถบด้านข้าง และไม่มีแบนเนอร์คุกกี้มาขวาง

## ถามเกี่ยวกับพื้นที่ทำงาน*ของคุณ*

เอกสารนี้อธิบายตัวระบบ สำหรับคำถามเกี่ยวกับข้อมูลของคุณเอง — การจอง รายได้ รายการที่พักของคุณ — ใช้ [ถาม Santi](/th/help/assistant/) ในระบบ Santi มีพื้นที่ทำงานของคุณ แต่แชตบอตที่ได้แค่ URL นี้ไม่มี
