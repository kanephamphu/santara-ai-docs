## ค้นหา — <kbd>⌘K</kbd>

กด <kbd>⌘K</kbd> (หรือ <kbd>Ctrl</kbd>+<kbd>K</kbd>) ได้ทุกที่ในระบบ การค้นหาครอบคลุมสี่อย่าง:

| | ค้นหาได้จาก |
| --- | --- |
| **การจอง** | ชื่อแขก รหัสยืนยัน วันที่ |
| **แขก** | ชื่อ อีเมล เบอร์โทร |
| **ที่พัก** | ชื่อ เมือง |
| **ห้องพัก** | ชื่อ หรือที่พักที่ห้องนั้นอยู่ |

ผลลัพธ์มีข้อมูลพอให้เลือกถูกโดยไม่ต้องเปิดดู การจองแสดงวันที่และสถานะ ห้องพักแสดงอาคารที่อยู่ วันที่และสถานะแสดงเป็นภาษา **ของคุณ** ไม่ใช่ภาษาของฐานข้อมูล

เป็นวิธีที่เร็วที่สุดในการเปิดการเข้าพักหนึ่งรายการเมื่อแขกโทรมา พิมพ์รหัสยืนยัน กด Enter เสร็จ — เร็วกว่าหน้า[การจอง](/th/daily/bookings/) ซึ่งออกแบบมาให้กวาดตาดูทั้งรายการ ไม่ใช่เปิดหาทีละรายการ

## ทัวร์แนะนำ

พื้นที่ทำงานใหม่จะมี **"พาชมระบบ"** — ประมาณยี่สิบขั้นตอนสั้น ๆ ที่ชี้ไปยังแต่ละส่วนของระบบและบอกว่าใช้ทำอะไร แบ่งเป็นบท: ทำความรู้จัก ทุกวัน ทุกสัปดาห์หรือราว ๆ นั้น การเปิดขาย และที่ขอความช่วยเหลือ

- **หยุดเมื่อไรก็ได้** ทัวร์จะเริ่มต่อจากจุดที่คุณค้างไว้ และปุ่มเล่นต่อจะบอกว่าคุณอยู่บทไหน แทนที่จะบอกว่า "ขั้นตอนที่ 11"
- **"ไม่ต้องแสดงอีก"** หมายความตามนั้นจริง ระบบจะไม่ถามคุณเป็นครั้งที่สอง
- **เริ่มทัวร์ใหม่** ได้จากขั้นตอนการตั้งค่าในหน้า [ที่พัก](/th/setup/properties/) หรือ [การตั้งค่า → ช่องทาง](/th/channels/)

ทัวร์ปรับตามคุณ ขั้นตอนของหน้าจอที่บทบาทของคุณเปิดไม่ได้จะถูกข้ามไป แทนที่จะพาคุณไปเจอการปฏิเสธ และขั้นตอนการตั้งค่าที่คุณทำไปแล้วจะไม่แสดง ส่วนของระบบที่แพ็กเกจของคุณไม่มีจะยังแสดงอยู่พร้อมไอคอนแม่กุญแจ — คุณเห็นได้ว่ามีอะไรอยู่ โดยไม่ถูกขายของกลางประโยค

:::note[ต้องใช้หน้าจอกว้าง]
ทัวร์ทำงานโดยชี้ไปที่สิ่งต่าง ๆ และบนโทรศัพท์ไม่มีอะไรให้ชี้ — เลย์เอาต์ต่างกัน เปิด Santara AI บนแล็ปท็อปเพื่อใช้ทัวร์นี้
:::

## รายการตรวจสอบการตั้งค่า

แยกจากทัวร์แนะนำ และเป็นสิ่งที่ควรทำตามก่อน: สามขั้นตอนจากพื้นที่ทำงานว่างเปล่าไปจนถึงเปิดขายบนช่องทางของคุณ ติดตามความคืบหน้าไปพร้อมกัน

1. [เชื่อมต่อบัญชีช่องทางของคุณ](/th/channels/)
2. [นำเข้ารายการที่พัก](/th/channels/airbnb/)
3. [ตรวจสอบราคาและรายละเอียด](/th/setup/properties/)

รายการนี้อยู่ด้านบนของหน้าที่พักและการตั้งค่า → ช่องทาง จนกว่าจะทำเสร็จ ไม่ได้ขายบน Airbnb หรือ Booking.com? รายการจะเสนอทางสร้างเองแทน — ดู [ที่พักและห้องพัก](/th/setup/properties/#สร้างเอง)
