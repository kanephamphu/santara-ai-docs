ส่วนอื่นของคู่มือนี้จัดตาม **หน้าจอ** หน้านี้จัดตาม **งาน** — สิ่งที่คุณตั้งใจมาทำจริง ๆ หาบรรทัดที่ตรง แล้วตามลิงก์ไป

ถ้าไม่มีอะไรตรง ให้[ค้นหา](/th/help/finding-things/) หรือถาม[ผู้ช่วย](/th/help/assistant/) — ผู้ช่วยอ่านพื้นที่ทำงานของคุณได้ จึงตอบจากข้อมูล*ของคุณ* ไม่ใช่ตอบแบบทั่วไป

## เริ่มต้นใช้งาน

| ฉันต้องการ… | ทำแบบนี้ |
| --- | --- |
| ตั้งค่าทั้งหมดตั้งแต่ศูนย์ | [เริ่มต้นอย่างรวดเร็ว](/th/start/quickstart/) — สี่ขั้นตอน ประมาณครึ่งชั่วโมง |
| เข้าใจคำต่าง ๆ บนทุกหน้าจอ | [Santara AI ประกอบขึ้นอย่างไร](/th/start/concepts/) |
| ลองใช้โดยไม่เชื่อมต่อช่องทาง | [สร้างที่พักเอง](/th/setup/properties/#สร้างเอง) |
| รู้ว่าอะไรจะเปลี่ยนเมื่อเชื่อมต่อ Airbnb | ไม่มีอะไรเปลี่ยน จนกว่าคุณจะกด เปิดขาย — [การเปิดขาย](/th/channels/going-live/) |
| รู้ว่าต้องทำอะไรทุกเช้า | [สัปดาห์แรกของคุณ](/th/start/first-week/) |
| เริ่มทัวร์แนะนำใหม่ | [การค้นหาสิ่งต่าง ๆ](/th/help/finding-things/) |
