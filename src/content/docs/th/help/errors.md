ข้อความในหน้านี้ยกมาตามที่ระบบแสดงทุกตัวอักษร คุณจึงค้นหาประโยคที่อยู่ตรงหน้าคุณได้ในหน้านี้ ถ้าไม่พบข้อความของคุณ ให้ทำตาม [เมื่อมีอะไรดูผิดปกติ](/th/help/troubleshooting/) หรือ [การแก้ปัญหาช่องทาง](/th/channels/troubleshooting/)

## การเข้าสู่ระบบ

| ข้อความ | ความหมาย | สิ่งที่ต้องทำ |
| --- | --- | --- |
| *อีเมลหรือรหัสผ่านไม่ถูกต้อง* | ตามนั้นเลย ระบบตั้งใจไม่บอกว่าอันไหนผิด | ลองอีกครั้ง หรือใช้ *ลืมรหัสผ่าน?* |
| *Too many failed attempts. Please try again later.* | เข้าสู่ระบบไม่สำเร็จสิบครั้ง บัญชีจึงถูกล็อก **15 นาที** | รอให้ครบเวลา หรือรีเซ็ตรหัสผ่าน — การรีเซ็ตปลดล็อกทันที ดู [ถ้าคุณถูกล็อกออกจากระบบ](/th/setup/account/#ถ้าถูกล็อกบัญชี) |
| *โปรดยืนยันอีเมลของคุณก่อนเข้าสู่ระบบ* | มีบัญชีแล้ว แต่ยังไม่เคยกรอกรหัสหกหลัก | ตรวจสอบกล่องจดหมาย รวมถึงโฟลเดอร์สแปม ขอรหัสใหม่ถ้ารหัสหมดอายุ |
| *มีบัญชีที่ใช้อีเมลนี้อยู่แล้ว* | คุณเคยลงทะเบียนไว้แล้ว อาจเป็นของพื้นที่ทำงานอื่น | เข้าสู่ระบบแทน — บัญชีเข้าสู่ระบบเดียวอยู่ได้หลายพื้นที่ทำงาน |
| *รหัสไม่ถูกต้อง โปรดตรวจสอบแล้วลองอีกครั้ง* | รหัสรีเซ็ตหรือรหัสยืนยันผิด | อ่านรหัสอีกครั้ง กรอกผิดห้าครั้งรหัสนั้นจะใช้ไม่ได้ |
| *รหัสนี้หมดอายุแล้ว โปรดขอรหัสใหม่* | รหัสมีอายุ **15 นาที** | ขอรหัสใหม่ — ขอได้นาทีละครั้ง |
| *กรอกรหัสผิดหลายครั้งเกินไป โปรดขอรหัสใหม่* | กรอกรหัสเดียวกันผิดห้าครั้ง | ขอรหัสใหม่ |
| *รหัสผ่านใหม่ต้องมีอย่างน้อย 12 ตัวอักษร* | สั้นเกินไป — รหัสผ่านใหม่ต้องมี 12 ตัวอักษรขึ้นไป | ใช้รหัสผ่านที่ยาวขึ้น วลีสั้น ๆ ไม่กี่คำง่ายที่สุด |
| *รหัสผ่านต้องมีไม่เกิน 128 ตัวอักษร* | ยาวเกินไป — 128 ตัวอักษรคือขีดสูงสุด | ใช้รหัสผ่านที่สั้นลง |
| *รหัสผ่านนี้เดาง่ายเกินไป ลองใช้วลีที่ยาวขึ้น* | อยู่ในรายการรหัสผ่านที่ใช้กันทั่วไป (*password1234* และแบบเดียวกัน) หรือเป็นตัวอักษรเดียวซ้ำ ๆ | เลือกรหัสผ่านที่ไม่มีใครคิดจะใช้ |
| *รหัสผ่านต้องไม่มีชื่อที่อยู่ในอีเมลของคุณ โปรดเลือกรหัสผ่านอื่น* | ส่วนของอีเมลก่อนเครื่องหมาย @ อยู่ในรหัสผ่าน | เลือกรหัสผ่านที่ไม่มีส่วนนั้น |
| *โปรดลงชื่อเข้าใช้อีกครั้ง* | เซสชันของคุณสิ้นสุดแล้ว — ส่วนใหญ่เพราะเปลี่ยนรหัสผ่านจากที่อื่น หรือเบราว์เซอร์ล้างคุกกี้ | เข้าสู่ระบบ ถ้าเกิดซ้ำ ดู [เซสชันของฉันหมดอายุบ่อย](/th/help/troubleshooting/#เซสชันของฉันหมดอายุบ่อย) |

:::note
ปัจจุบันข้อความการล็อกบัญชียังแสดงเป็นภาษาอังกฤษ แม้ส่วนอื่นของหน้าเข้าสู่ระบบจะเป็นภาษาอินโดนีเซีย เวียดนาม หรือไทย
:::

## การเชื่อมต่อช่องทาง

| ข้อความ | ความหมาย | สิ่งที่ต้องทำ |
| --- | --- | --- |
| *เบราว์เซอร์ของคุณบล็อกป๊อปอัป โปรดอนุญาตป๊อปอัปแล้วลองอีกครั้ง* | Airbnb ให้สิทธิ์ผ่านหน้าต่างป๊อปอัป | อนุญาตป๊อปอัปสำหรับเว็บไซต์ แล้วกด *เชื่อมต่อ Airbnb* อีกครั้ง |
| *การอนุญาตไม่เสร็จสมบูรณ์* | คุณปิดหน้าต่างของ Airbnb ก่อนอนุมัติ **ยังไม่มีอะไรถูกเชื่อมต่อ** | กด *ลองอีกครั้ง* |
| *บัญชี Airbnb นี้เชื่อมต่ออยู่แล้ว* | บัญชี Airbnb เดียวกันอยู่ในการเชื่อมต่ออื่นในพื้นที่ทำงานนี้ | ยกเลิกการเชื่อมต่อเดิมก่อน แล้วเชื่อมต่อใหม่ ดู [เพิ่มบัญชีอื่น](/th/channels/listings/#เพิ่มบัญชีอื่น) |
| *บัญชีนี้เชื่อมต่ออยู่แล้ว — กำลังพาคุณไปที่บัญชีนั้น* | สถานการณ์เดียวกัน ระบบจัดการให้แล้ว | ไม่ต้องทำอะไร คุณจะไปที่หน้าของการเชื่อมต่อเดิม |
| *เชื่อมต่อแล้ว* (บนแถวของรายการที่พัก) | รายการที่พักนั้นจับคู่กับห้องพักที่ไหนสักแห่งแล้ว | เลือกรายการที่พักอื่น หรือยกเลิกการลิงก์รายการเดิม |
| *โหลดรายการที่พัก Airbnb ของคุณไม่ได้* | เราติดต่อ Airbnb ได้ แต่ไม่ได้อะไรกลับมา | กด **รีเฟรช** ที่การเชื่อมต่อ ถ้าเกิดซ้ำ ให้เชื่อมต่อบัญชีใหม่ |
| *เริ่มการเชื่อมต่อ Airbnb ไม่ได้* | การเชื่อมต่อเบื้องต้นล้มเหลวก่อนถึง Airbnb | ลองอีกครั้ง ถ้ายังเป็นอยู่ [ติดต่อทีมซัพพอร์ต](/th/help/support/) |
| *เริ่มการนำเข้าไม่ได้* | อ่านรายการที่พักได้แล้ว แต่งานนำเข้าไม่เริ่ม | ลองอีกครั้ง ไม่มีอะไรถูกสร้างค้างไว้ครึ่งทาง |
| *เชื่อมต่อที่พัก Booking.com ไม่ได้* | Hotel ID ถูกปฏิเสธ หรือขั้นตอนใน extranet ยังไม่ครบ | ตรวจสอบ Hotel ID อีกครั้ง และตรวจว่าเปิดใช้ผู้ให้บริการของเราใน extranet แล้ว — [เชื่อมต่อ Booking.com](/th/channels/booking-com/) |

## การนำเข้าและการอ่านราคา

| ข้อความ | ความหมาย | สิ่งที่ต้องทำ |
| --- | --- | --- |
| *ตั้งค่าแล้ว — ยังไม่เปิดขาย* | ผลลัพธ์ปกติและถูกต้องเมื่อนำเข้าเสร็จ จับคู่และอ่านข้อมูลแล้ว **ช่องทางยังคุมปฏิทินอยู่** | ตรวจสอบราคาและรายละเอียด แล้ว[เปิดขาย](/th/channels/going-live/) |
| *เราอ่านราคาของรายการที่พักนี้อย่างปลอดภัยไม่ได้ ห้องพักจึงใช้ราคาเดิมของตัวเอง ไม่มีการคาดเดาใดๆ* | ราคาของช่องทางกำกวม ระบบนำเข้าเลือกที่จะไม่ทำ แทนที่จะสร้างตัวเลขขึ้นมาเอง | ตั้งราคาให้ห้องพักก่อนเปิดขาย |
| *Airbnb ยังไม่ได้แชร์ราคาของรายการที่พักนี้* | Airbnb ยังไม่ส่งราคามาให้ ไม่ใช่ข้อผิดพลาด | ไม่ต้องทำอะไร — ราคาจะมาในการซิงค์ครั้งถัดไป |
| *เรานำลิงก์ช่องทางออกชั่วคราว… ระบบจะลิงก์ใหม่โดยอัตโนมัติเมื่ออ่านราคาได้* | ราคาศูนย์หรือราคาที่อ่านไม่ได้จะถูกเผยแพร่ไปยังรายการที่พักที่เปิดขายอยู่ จึงระงับลิงก์ไว้ก่อน | ตั้งราคาจริงให้ห้องพัก ลิงก์จะกลับมาเอง |
| *ควรตรวจสอบบน Airbnb — รายการเหล่านี้ดูผิดปกติและเราไม่ต้องการคาดเดา:* | ค่าที่นำเข้ามาแล้วแต่ดูแปลก | เปิดดูบน Airbnb และยืนยัน ค่าเหล่านี้ยังมีผลอยู่ที่นั่น |
| *คงไว้บน Airbnb* | การตั้งค่าที่เราไม่มีสิ่งที่เทียบเท่าได้ตรง ๆ | ไม่ต้องทำอะไร การตั้งค่ายังทำงานบน Airbnb |

## การเปิดขาย

| ข้อความ | ความหมาย | สิ่งที่ต้องทำ |
| --- | --- | --- |
| *Airbnb ยังลิงก์รายการที่พักนี้ไม่เสร็จ ลองอีกครั้งในอีกหนึ่งนาที* | การตั้งค่าฝั่งช่องทางยังดำเนินอยู่ | รอหนึ่งนาที แล้วกด **เปิดขาย** อีกครั้ง |
| *สกุลเงินของรายการที่พักยังไม่ได้ซิงค์ ลองอีกครั้งในไม่ช้า* | สกุลเงินมาแยกต่างหากและยังมาไม่ถึง | รอสักสองสามนาที แล้วลองใหม่ |
| *ห้องพักนี้ขาดการตั้งค่าช่องทาง นำเข้ารายการที่พักอีกครั้ง* | การจับคู่ฝั่งเรายังไม่ครบ | นำรายการที่พักนั้นออก แล้วนำเข้าใหม่ |
| *Airbnb ไม่ได้ยืนยันว่าเปิดขายแล้ว* | เราถามไปแล้ว แต่ Airbnb ไม่ได้ตอบรับ | ลองใหม่หนึ่งครั้ง ถ้ายังเกิดซ้ำ [ติดต่อทีมซัพพอร์ต](/th/help/support/) |
| *บางรายการที่พักยังไม่เปิดขาย รายการเหล่านั้นยังตั้งค่าไว้และคุณลองอีกครั้งได้* | สำเร็จบางส่วน รายการที่เหลือ **เปิดขายแล้ว** | ลองใหม่เฉพาะรายการที่ล้มเหลว ไม่มีอะไรหายไป |
| *จับคู่ห้องพักแล้ว แต่ช่องทางยังไม่เปิดใช้งาน* | Booking.com ยังไม่เปิดใช้งานการเชื่อมต่อ | การจอง รีวิว และข้อความจะซิงค์เมื่อเปิดใช้งานสำเร็จ |

## ห้องพักและแผนราคาของ Booking.com

| ข้อความ | ความหมาย | สิ่งที่ต้องทำ |
| --- | --- | --- |
| *…ยังคงลิงก์อยู่แต่ไม่ได้จับคู่ — แผนราคาของห้องไม่ได้กำหนดราคาสำหรับจำนวนแขกที่ Booking.com ยอมรับ* | จำนวนแขกที่รวมในแผนราคาไม่ตรงกับจำนวนผู้เข้าพักที่ Booking.com รับ เราจะไม่คาดเดาบนรายการที่พักที่เปิดขายอยู่ | เปิดแผนราคาของห้อง ตั้งจำนวนแขกให้ตรงกัน แล้วจับคู่อีกครั้ง |
| *…ตั้งราคาเป็นสกุลเงินหนึ่ง แต่โรงแรมนี้เรียกเก็บเงินเป็นอีกสกุลเงินหนึ่ง การจับคู่ยังทำงาน แต่การส่งราคาจะถูกปฏิเสธจนกว่าจะตรงกัน* | สกุลเงินของแผนราคากับโรงแรมไม่ตรงกัน | แก้สกุลเงินของแผนราคาก่อนจะคาดหวังให้ราคาส่งออกไป |
| *บันทึกที่นี่แล้ว แต่ Booking.com ไม่ยอมรับการจับคู่ราคา* | ฝั่งเราถูกต้อง แต่ฝั่งเขาไม่รับ | บันทึกอีกครั้ง ถ้ายังล้มเหลว ให้เชื่อมต่อที่พักใหม่ |
| *บันทึกที่นี่แล้ว แต่ยังไม่ส่งไปยังช่องทาง — ยืนยันความจุของห้องนี้ก่อน* | การระงับเพื่อความปลอดภัยก่อนเขียนลงรายการที่พักที่เปิดขายอยู่ | ยืนยันความจุ และตรวจว่าจำนวนยูนิตถูกต้อง |
| *ปฏิทินของคุณจะถูกเขียนลงในรายการที่พักที่เปิดขายอยู่ทันที…* | ไม่ใช่ข้อผิดพลาด — เป็นคำเตือนว่าการยืนยันจะปิดคืนที่กำลังจะมาถึงตามจำนวนยูนิตที่แสดง | ตรวจสอบจำนวนยูนิตก่อนยืนยัน อพาร์ตเมนต์หนึ่งห้องคือหนึ่งยูนิต |
| *เปลี่ยนที่พักที่ลิงก์ไว้ไม่ได้* | การลิงก์ใหม่ไม่เสร็จสมบูรณ์ | ลองใหม่ ข้อมูลที่นำเข้าแล้วยังอยู่ที่เดิมไม่ว่าในกรณีใด |

## คำบอกสถานะการเชื่อมต่อ

สิ่งเหล่านี้คือสถานะ ไม่ใช่ข้อผิดพลาด ใช้คำชุดเดียวกันในทุกช่องทาง

| สถานะ | ความหมาย |
| --- | --- |
| **ยังไม่ได้เชื่อมต่อ** | ยังไม่ได้เชื่อมบัญชีช่องทางใด |
| **ยังไม่ได้ลิงก์** | เราเห็นรายการที่พัก แต่ยังไม่ได้ชี้ไปที่ห้องพักใด |
| **ลิงก์แล้ว — ยังไม่ได้จับคู่** | แบบเดียวกัน แต่เป็นคำที่ใช้บนหน้าจอ Booking.com |
| **ลิงก์แล้ว — ยังไม่ได้จับคู่ราคา** | จับคู่ห้องว่างแล้ว แต่แผนราคายังไม่ได้จับคู่ |
| **พร้อม — ยังไม่เปิดขาย** | จับคู่และตั้งราคาแล้ว รอคุณกด **เปิดขาย** |
| **จับคู่แล้ว — รอการเปิดใช้งาน** | ชี้ไปที่ห้องพักแล้ว แต่ช่องทางยังไม่ส่งมอบการควบคุม |
| **เปิดขายแล้ว** | ราคาและห้องว่างส่งออกไป การจองและข้อความเข้ามา |
| **ข้อผิดพลาด** | มีบางอย่างล้มเหลว — แถวนั้นบอกว่าอะไร: *การนำเข้าราคาถูกบล็อก*, *เปิดใช้งานไม่สำเร็จ* |
| **ยังไม่ได้ซิงค์** | เชื่อมต่อแล้ว แต่ยังไม่มีการซิงค์ครั้งใดเสร็จ |

ไม่มีอะไรเปลี่ยนจาก *พร้อม* เป็น *เปิดขายแล้ว* ได้เอง ดู [การเปิดขาย](/th/channels/going-live/)

## การเรียกเก็บเงิน

| ข้อความ | ความหมาย | สิ่งที่ต้องทำ |
| --- | --- | --- |
| *การชำระเงินครั้งล่าสุดของคุณไม่สำเร็จ* | Stripe เรียกเก็บเงินจากบัตรไม่ได้ | อัปเดตบัตร Stripe จะลองเรียกเก็บใหม่เองด้วย |
| *การสมัครใช้งานของคุณไม่ได้ใช้งานอยู่ พื้นที่ทำงานนี้จึงเป็นแบบอ่านอย่างเดียว* | ไม่มีอะไรถูกลบ คุณแค่แก้ไขไม่ได้ | จัดการเรื่องการเรียกเก็บเงินให้เรียบร้อย ทุกอย่างจะกลับมาทำงาน — [ถ้าการชำระเงินล้มเหลว](/th/setup/billing/#ถ้าการชำระเงินล้มเหลว) |
| *บัตรของคุณถูกปฏิเสธ จึงไม่มีการเรียกเก็บเงินและไม่ได้เพิ่มรายการที่พัก* | การซื้อรายการที่พักเพิ่มล้มเหลวโดยไม่มีผลค้าง | อัปเดตบัตร แล้วเพิ่มรายการที่พักอีกครั้ง |
| *การดำเนินการนี้จะเพิ่มรายการที่พักเกินกว่าที่แพ็กเกจครอบคลุม* | คุณใช้จำนวนรายการที่พักที่จ่ายไว้ครบแล้ว | ใช้ **เพิ่มห้องพัก** ซึ่งแสดงราคา หรือปล่อยรายการที่พักหนึ่งรายการให้ว่าง — [การเพิ่มรายการที่พักกลางเดือน](/th/setup/billing/#เพิ่มรายการที่พักระหว่างเดือน) |
| *เริ่มทดลองใช้ฟรีก่อน: เพิ่มบัตรในหน้าการเรียกเก็บเงิน* | การนำเข้าจะสร้างรายการที่พัก แต่ยังไม่มีบัตร | เพิ่มบัตร ไม่มีการเรียกเก็บเงินในวันนั้น |
| *ราคาเปลี่ยนไประหว่างที่เปิดหน้านี้* | ใบเสนอราคาล้าสมัยระหว่างที่หน้าต่างเปิดค้างไว้ | ยืนยันอีกครั้งเพื่อดำเนินการต่อ |
| *เฉพาะเจ้าของพื้นที่ทำงานเท่านั้นที่เปลี่ยนแพ็กเกจได้* | โฮสต์ร่วมอ่านข้อมูลการเรียกเก็บเงินได้ แต่เปลี่ยนไม่ได้ | ขอให้เจ้าของทำ |
| *แพ็กเกจของคุณใช้ราคาที่ตกลงไว้ ติดต่อเราแล้วเราจะย้ายให้คุณ* | คุณใช้เงื่อนไขที่ตกลงกันไว้ ไม่ใช่แพ็กเกจที่ประกาศไว้ | [ติดต่อทีมซัพพอร์ต](/th/help/support/) |
| *ไม่รู้จักโค้ดนี้* / *โค้ดนี้หมดอายุแล้ว* / *โค้ดนี้ถูกใช้ครบแล้ว* | ปัญหาของโค้ดส่วนลด ตามที่ข้อความบอกตรงตัว | ดำเนินการต่อโดยไม่ใช้โค้ด หรือสอบถามแหล่งที่คุณได้โค้ดมา |
| *แพ็กเกจของคุณมีส่วนลดอยู่แล้ว* | ใช้โค้ดร่วมกับส่วนลดที่มีอยู่ไม่ได้ | ไม่ต้องทำอะไร — ราคาของคุณรวมส่วนลดไว้แล้ว |

## การเข้าถึงและสิทธิ์

| ข้อความ | ความหมาย | สิ่งที่ต้องทำ |
| --- | --- | --- |
| หน้าจอบอกว่าคุณไม่มีสิทธิ์เข้าถึง | บทบาทของคุณไม่มีสิทธิ์ที่หน้าจอนั้นต้องใช้ | ตรวจว่าคุณอยู่ในพื้นที่ทำงานที่ถูกต้อง (เมนูบัญชี) แล้วขอเจ้าของ — [ทีมและบทบาท](/th/setup/team/) |
| *การตั้งค่าพื้นที่ทำงานเป็นแบบอ่านอย่างเดียวสำหรับบทบาทของคุณ* | โฮสต์ร่วมและพนักงานทำความสะอาดเห็นการตั้งค่าพื้นที่ทำงานได้ แต่เปลี่ยนไม่ได้ | เจ้าของเป็นผู้เปลี่ยน — [ได้รับเชิญเป็นโฮสต์ร่วมหรือผู้จัดการ](/th/start/invited-manager/) |
| *การตั้งค่าพื้นที่ทำงานจัดการโดยเจ้าของพื้นที่ทำงาน* | แสดงให้พนักงานทำความสะอาดเห็นในหน้าการตั้งค่า | เป็นเรื่องปกติ การตั้งค่าบัญชีของคุณเองยังใช้ได้ |
| *Unsupported team role.* | คำเชิญระบุบทบาทที่เชิญไม่ได้ | ปัจจุบันเชิญได้เฉพาะ **โฮสต์ผู้ดูแล** **โฮสต์ร่วม** และ **พนักงานทำความสะอาด** |

## สิ่งที่ดูเหมือนข้อผิดพลาดแต่ไม่ใช่

| บนหน้าจอ | ทำไมจึงไม่เป็นไร |
| --- | --- |
| หน้าจอว่างเปล่าทันทีหลังเชื่อมต่อ | การนำเข้าประวัติทำงานเบื้องหลัง และใช้เวลาสองสามนาทีสำหรับบัญชีขนาดใหญ่ รอห้านาทีแล้วรีเฟรช |
| ไม่มีงานทำความสะอาดสำหรับพรุ่งนี้ | งานเปลี่ยนแขกถูกสร้างในคืนก่อนวันเช็คเอาท์ สำหรับวันนั้นเท่านั้น |
| ไม่มีการแจ้งเตือนสำหรับการจองตลอดทั้งปี | การซิงค์ครั้งแรกตั้งใจให้เงียบ — ประวัติที่นำเข้าไม่ใช่การจองใหม่ |
| ห้องว่างน้อยกว่าที่คุณตั้งไว้ | จำนวนห้องว่างถูกจำกัดไว้ที่ **จำนวนยูนิต** ของห้องพัก อพาร์ตเมนต์หนึ่งห้องคือหนึ่งยูนิต |
| รายได้ต่ำกว่าใน extranet | ของเราคือ **ยอดที่ได้รับสุทธิ** ส่วน extranet มักแสดงยอดรวม ทั้งสองค่าถูกเก็บไว้ — [คำจำกัดความด้านการเงิน](/th/daily/bookings/#ความหมายของตัวเลขเงิน) |
