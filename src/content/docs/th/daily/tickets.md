**ใบงาน** คืออะไรก็ตามที่ต้องแก้ไขหรือติดตาม: แอร์เสีย คำร้องเรียนของแขก ซัพพลายเออร์ที่ต้องโทรหา ใบงานอยู่ข้างงานทำความสะอาดใน[งาน](/th/daily/tasks/) และมีหน้าจอของตัวเองเมื่อคุณอยากดูรายการทั้งหมด

ใบงานเป็นเรื่องภายใน **แขกไม่เคยเห็นใบงาน** แม้แต่ใบที่เปิดจากข้อความของแขกเอง

![รายการใบงาน: สถานะ คนที่ได้รับมอบหมาย และที่พักที่มา](/screens/tickets.th.png)

## ใบงานเปิดขึ้นเอง

ใบงานส่วนใหญ่ไม่ได้สร้างโดยคน ข้อความของแขกที่อ่านแล้วเป็นคำร้องเรียนหรือปัญหาการซ่อมบำรุงจะเปิดใบงานโดยอัตโนมัติ ลิงก์กลับไปยังบทสนทนาและที่พัก — การแก้ไขจึงถูกติดตามในที่อื่นนอกจากบทสนทนาที่เลื่อนหายไป

กฎสามข้อไม่ให้สิ่งนี้กลายเป็นเสียงรบกวน:

- **หนึ่งบทสนทนา หนึ่งใบงาน ตลอดไป** ไม่ว่าการจัดประเภทจะทำงานกี่ครั้ง บทสนทนาที่สร้างใบงานไปแล้วจะไม่สร้างใบที่สอง
- **เฉพาะสองสัปดาห์ล่าสุด** บทสนทนาที่ไม่มีใครแตะมาสองสัปดาห์คือประวัติ ไม่ใช่งาน
- **ไม่ท่วมในวันแรก** การเชื่อมต่อประวัติข้อความหนึ่งปีจะไม่เปิดใบงานสามร้อยใบ — เฉพาะใบล่าสุดที่ยังมีคนจัดการได้

คุณยังสร้างใบงานเองได้ จากหน้าจอนี้ หรือโดยเลือกวันที่บน[ปฏิทิน](/th/daily/calendar/)

## จัดการใบงาน

เปิดใบงานเพื่อดูข้อมูลทั้งหมด:

| | |
| --- | --- |
| **สถานะ** | ตั้งแต่เปิดจนเสร็จ |
| **ผู้รับผิดชอบ** | เพื่อนร่วมทีม ได้รับการแจ้งเตือนเมื่อใบงานถูกมอบหมายให้ และอีกครั้งเมื่อเสร็จ |
| **ที่พักและห้อง** | ดึงมาจากข้อความที่เป็นต้นทาง |
| **บทสนทนากับแขก** | ลิงก์กลับไปยังการสนทนา เพื่อให้คุณตอบได้โดยไม่เสียบริบท |
| **รูปภาพ** | หลักฐาน ก่อนและหลัง |
| **กำหนดเวลา** | ช่วงวันที่ — ดูด้านล่าง |

### กำหนดเวลาแล้วจะแสดงบนปฏิทิน

ให้ช่วงวันที่กับใบงาน แล้ว **ใบงานจะแสดงบน[ปฏิทิน](/th/daily/calendar/)** เป็นบล็อกลายทางพาดผ่านคืนเหล่านั้น งานซ่อมสองวันจึงเห็นได้ชัดเทียบกับการจองรอบ ๆ ซึ่งคือจุดประสงค์: คุณเห็นได้ว่าชนกับแขกที่จะมาถึงหรือไม่ก่อนตัดสินใจ

ใบงานไม่ได้ปิดคืนเหล่านั้นเอง ถ้าห้องขายไม่ได้จริง ๆ ให้ปิดวันที่ในปฏิทินด้วย

### แผนแก้ไขจาก AI

ขอแผนแล้วคุณจะได้สาเหตุที่น่าจะเป็นและวิธีแก้ทีละขั้นตอน สร้างจากใบงาน ที่พัก และประวัติของที่พัก เป็นจุดเริ่มต้นสำหรับคนที่ลงมือทำ — มีประโยชน์เป็นพิเศษเมื่อส่งงานให้คนที่ไม่เคยเห็นอาคารนั้นมาก่อน

แผนเป็นแค่ร่าง ไม่สั่งอะไหล่ ไม่ส่งข้อความถึงแขก และไม่ปิดใบงาน

## ใบงานที่ปิดแล้วอยู่บนกระดานนานเท่าไร

ใบงานที่เปิดอยู่แสดงเสมอ ใบงานที่ **เสร็จแล้ว** และ **ยกเลิกแล้ว** จะอยู่บนกระดาน **30 วันหลังการอัปเดตครั้งล่าสุด** แล้วหายไปจากกระดาน เพื่อให้กระดานแสดงเฉพาะงานปัจจุบัน ไม่มีอะไรถูกลบ: ใบงานและประวัติยังอยู่

## ใครเห็นได้บ้าง

ใบงานใช้[กฎสิทธิ์](/th/setup/team/)เดียวกับทุกอย่าง สมาชิกที่ไม่มีสิทธิ์เข้าถึงใบงานจะได้รับแจ้งอย่างตรงไปตรงมา แทนที่จะเห็นรายการว่างที่เขาจะแจ้งว่าระบบเสีย ถ้าคุณคิดว่าควรมีสิทธิ์แต่ไม่มี ให้ขอเจ้าของหรือผู้จัดการของพื้นที่ทำงาน
