**วันนี้** คือหน้าจอเริ่มต้น มีสองส่วน: **สรุปประจำวัน** ซึ่งเล่าวันนี้เป็นประโยค และช่องตัวชี้วัดด้านล่างซึ่งเป็นตัวเลข

![วันนี้ สรุปด้านบนบอกว่าเรื่องไหนต้องตัดสินใจ ช่องด้านล่างคือตัวเลขเบื้องหลัง](/screens/today.th.png)

## สรุป

ระบบสร้างสรุปให้พื้นที่ทำงานของคุณทุกวันและส่งทางอีเมล — เวลา **06:00** ตามเขตเวลาของพื้นที่ทำงานโดยค่าเริ่มต้น หรือชั่วโมงที่คุณเลือก — เป็น **ภาษา** ที่คุณตั้งไว้ใน[การตั้งค่าพื้นที่ทำงาน](/th/setup/workspace/#การตั้งค่าการปฏิบัติงาน) สรุปเดียวกันนี้อยู่บนหน้าจอนี้ด้วย และอัปเดตไปตามวัน เป็นแผ่นเดียวที่อัดแน่น เรียงตามลำดับนี้:

1. **แถบหัว** — วันที่ จำนวนเช็คอิน เช็คเอาท์ และงานเปลี่ยนแขกของวันนี้ และเวลาของพนักงานทำความสะอาดที่มีงานจองไว้แล้วเท่าไร
2. **สรุปผลงาน** — รายได้วันนี้ อัตราการเข้าพัก และราคาเฉลี่ยต่อคืน แต่ละตัวเทียบกับยอดตั้งแต่ต้นเดือน
3. **ข้อมูลเชิงลึกจาก AI** — การ์ดหนึ่งใบต่อแขกหรือปัญหาหนึ่งเรื่องที่ต้องจัดการ บอกว่าเกิดอะไรขึ้นและควรทำอะไร: การเช็คเอาท์ที่มีความเสี่ยง คำถามที่ยังไม่ได้ตอบ คำร้องเรียนที่ก่อตัวมาสามข้อความ งานทำความสะอาดที่ยังไม่มีคนรับ ใบงานที่ค้างอยู่ การ์ดแต่ละใบลิงก์ไปยังบทสนทนาหรือการเข้าพักนั้นโดยตรง
4. **โอกาสขายบริการเสริม** — เช็คเอาท์ล่าช้า เช็คอินก่อนเวลา และคืนเพิ่มที่ปฏิทินรับได้จริง แต่ละรายการมีราคาและข้อความที่จะส่ง
5. **งานทำความสะอาด สามวันข้างหน้า** — จัดกลุ่มตาม[กลุ่มงานทำความสะอาด](/th/daily/tasks/#กลุ่มงานทำความสะอาด) แต่ละกลุ่มมีเมนู **แชร์** ที่เขียนแผนของวันนั้นไว้แล้ว — ส่งไปยัง Zalo, WhatsApp, Messenger หรือ Telegram ได้ในแตะเดียว หรือคัดลอก พนักงานทำความสะอาดที่มีอีเมลจะได้รับอีเมล Cleaner Brief ของตัวเองโดยอัตโนมัติ โดยไม่มีข้อมูลรายได้
6. **พรุ่งนี้** — หนึ่งบรรทัดบอกเช็คอิน เช็คเอาท์ และงานเปลี่ยนแขกของพรุ่งนี้

ไม่มีอะไรในสรุปถูกส่งถึงแขกหรือพนักงานทำความสะอาดเอง: ทุกข้อความรอให้คุณเป็นคนส่ง

### ทำเครื่องหมายว่าตรวจแล้ว

กด **ทำเครื่องหมายว่าตรวจสอบทั้งหมดแล้ว** เมื่ออ่านครบแล้ว เป็นสัญญาณบอกคนอื่นในทีมว่ามีคนดูแล้ว ไม่ใช่คะแนนความสำเร็จ — ไม่มีอะไรถูกซ่อนหลังจากกด

### แชร์สรุป

**แชร์** เขียนข้อความสำหรับช่องทางที่คุณเลือก — อีเมล WhatsApp หรือข้อความ SMS — พร้อมไฮไลต์ของวันนี้และลิงก์ไปยังสรุปฉบับเต็ม แต่ละช่องทางได้ข้อความที่เขียนมาสำหรับช่องทางนั้น ไม่ใช่ย่อหน้าเดียวกันวางซ้ำสามครั้ง

ลิงก์จะเปิดสรุปฉบับเต็มใน Santara AI ผู้รับจึงต้องมีบัญชีที่เข้าถึงพื้นที่ทำงานนี้ได้ สำหรับพนักงานทำความสะอาดที่ไม่ควรเห็นภาพรวมของที่พักทั้งหมด ให้แชร์ **ข้อความของกลุ่ม** แทน: มีเฉพาะงานของพวกเขา

### ภาษาและเวลา

สรุปเขียนเป็นภาษาของพื้นที่ทำงานและส่งในชั่วโมงที่คุณเลือก (06:00 ถ้าคุณไม่ได้เปลี่ยน) ทั้งสองอย่างตั้งได้ใน[การตั้งค่าพื้นที่ทำงาน](/th/setup/workspace/) "วันนี้" ของสรุปอิงตามเขตเวลาของพื้นที่ทำงาน — ซึ่งสำคัญกว่าที่คิด เพราะสรุปที่สร้างในเขตเวลาผิดจะรายงานการเช็คเอาท์ของเมื่อวาน

## ช่องตัวชี้วัด

ใต้สรุป: จำนวนเช็คอินและเช็คเอาท์ อัตราการเข้าพัก รายได้ของช่วงเวลา งานที่ค้างอยู่ ข้อความที่ยังไม่ได้ตอบ แต่ละช่องเป็นลิงก์ไปยังหน้าจอเบื้องหลัง

**รายได้หมายถึงยอดที่ได้รับสุทธิ** — สิ่งที่ช่องทางจ่ายให้คุณจริง มีป้ายระบุไว้แบบนี้ทุกที่ที่แสดง ดูภาพรวมทั้งหมดได้ที่[รายงาน](/th/money/reports/)

## การแจ้งเตือน

อะไรก็ตามที่ต้องการคุณขณะที่คุณไม่ได้ดูหน้าจอนี้ จะสร้างการแจ้งเตือนในเมนูกระดิ่ง มีแปดประเภท และเป็นแปดเรื่องที่เปลี่ยนวันของคุณจริง ๆ:

| | |
| --- | --- |
| **การจอง** | การจองใหม่ การจองที่เปลี่ยนแปลง การยกเลิก |
| **ทำความสะอาด** | งานทำความสะอาดที่มอบหมายให้คุณ งานทำความสะอาดที่ทำเสร็จแล้ว |
| **ใบงาน** | ใบงานที่เปิดใหม่ มอบหมายให้คุณ หรือเสร็จแล้ว |

การแจ้งเตือนส่งถึง **คนที่ลงมือจัดการได้** ไม่ใช่ตามชื่อ ผู้จัดการที่เพิ่มเข้ามาเดือนหน้าจึงเห็นการแจ้งเตือนที่ตั้งใจไว้สำหรับบทบาทของเขามาตลอด ตั้งค่าสิ่งที่คุณได้รับได้ใน[การตั้งค่าพื้นที่ทำงาน](/th/setup/workspace/#การแจ้งเตือน)
