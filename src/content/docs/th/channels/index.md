Santara AI คือระบบจัดการช่องทางของคุณ ทำหน้าที่เชื่อมต่อช่องทางที่คุณใช้ขาย เมื่อรายการที่พักเปิดขายแล้ว
ข้อมูลสี่อย่างจะไหลไปมา:

| ทิศทาง | สิ่งที่เคลื่อนที่ |
| --- | --- |
| **ออกไปยังช่องทาง** | ห้องว่าง ราคาต่อคืน จำนวนคืนขั้นต่ำ ข้อจำกัดต่าง ๆ |
| **เข้ามาจากช่องทาง** | การจอง การยกเลิก แขก ข้อความ รีวิว |
| **เข้ามาครั้งเดียว ตอนนำเข้า** | รายละเอียดรายการที่พัก — ชื่อ รูปภาพ สิ่งอำนวยความสะดวก ความจุ ราคาที่มีอยู่ |
| **ออกไปเมื่อคุณสั่ง** | คำตอบของคุณต่อข้อความของแขก คำตอบของคุณต่อรีวิว |

Santara AI ไม่เคยเขียนทับเนื้อหารายการที่พัก **Airbnb** ของคุณ — ชื่อ คำอธิบาย และรูปภาพยังคงเป็นอย่างที่อยู่บน
Airbnb และไม่เคยเปลี่ยนราคาบนช่องทางที่คุณไม่ได้พิมพ์เอง หรือไม่ได้ให้กฎการตั้งราคาคำนวณ

บน **Booking.com และช่องทางอื่น ๆ** เนื้อหาของที่พักจะถูกส่งไปด้วย เมื่อคุณบันทึกที่พักหรือห้องพัก
Santara AI จะส่งรูปภาพ (สูงสุด 30 รูป) คำอธิบาย กฎของที่พัก นโยบายการยกเลิก และสิ่งอำนวยความสะดวกไปยังระบบจัดการช่องทาง ซึ่งจะส่งต่อไปยังช่องทางที่รับข้อมูลเหล่านี้

![ห้องว่างและราคาออกไปยังช่องทาง การจอง แขก ข้อความ และรีวิวเข้ามา รายละเอียดรายการที่พักเข้ามาครั้งเดียว ตอนนำเข้า](/diagrams/sync-directions.th.svg)

## ช่องทางที่รองรับ

Santara AI เชื่อมต่อกับ **ช่องทางการขาย 54 ช่องทาง** รวมถึงเว็บไซต์จองตรงของคุณเอง ทุกช่องทาง รวมทั้ง Airbnb และ
Booking.com เป็นไทล์หนึ่งใน **การตั้งค่า → ช่องทาง → เพิ่มช่องทาง** กด **เชื่อมต่อ** บนไทล์
แล้วขั้นตอนการตั้งค่าสามขั้นจะเปิดขึ้น

| ช่องทาง | วิธีเชื่อมต่อ |
| --- | --- |
| **Airbnb** | เชื่อมต่อ เลือกรายการที่พัก นำเข้า Santara AI สร้างที่พักและห้องพักจากรายการที่พักของคุณ — [เชื่อมต่อ Airbnb](/th/channels/airbnb/) |
| **Booking.com** | เลือกที่พัก เชื่อมต่อและจับคู่ (Hotel ID ของคุณ) นำเข้า — [เชื่อมต่อ Booking.com](/th/channels/booking-com/) |
| **ช่องทางอื่นทั้งหมด** — Agoda, Expedia, Trip.com, Traveloka, Tiket.com, Hostelworld และอื่น ๆ | เลือกที่พัก เชื่อมต่อและจับคู่ นำเข้า — [เชื่อมต่อช่องทางอื่น](/th/channels/other-channels/) |
| **เว็บไซต์จองตรงของคุณ** | มีอยู่ใน Santara AI ไม่ต้องเชื่อมต่อ — [เว็บไซต์จองตรงของคุณ](/th/setup/booking-site/) |

**ทุกช่องทางยกเว้น Airbnb ต้องมีที่พักที่มีห้องพักก่อน** ถ้ายังไม่มี ไทล์ของช่องทางจะแสดง
**เพิ่มที่พักก่อน** — การเชื่อมต่อช่องทางจะจับคู่ห้องพักที่คุณมีอยู่แล้ว ไม่ได้สร้างห้องพักใหม่ เพิ่มที่พักได้ที่
[ที่พัก](/th/setup/properties/) หรือเชื่อมต่อ Airbnb ก่อนแล้วให้ระบบสร้างให้

:::note[PriceLabs หยุดชั่วคราว]
การเชื่อมต่อ PriceLabs ใหม่หยุดชั่วคราว PriceLabs จึงไม่มีไทล์ การเชื่อมต่อ PriceLabs ที่คุณมีอยู่แล้วยังทำงานต่อและยังยกเลิกการเชื่อมต่อได้
:::

ทุกช่องทางได้รับปฏิทิน ราคา และข้อจำกัดชุดเดียวกัน และนำการจอง การยกเลิก และแขกเข้ามา
มีสองอย่างที่แตกต่างกันตามช่องทาง:

- **ข้อความของแขก** การตอบกลับส่งออกไปได้บน **Airbnb, Booking.com และ Expedia** เท่านั้น — เป็นช่องทางที่ส่งข้อความของแขกผ่านการเชื่อมต่อ สำหรับช่องทางอื่น ให้ตอบแขกในกล่องข้อความของช่องทางนั้นเอง
- **รีวิว** เข้ามา และตอบกลับได้ ในช่องทางที่ส่งรีวิวต่อมา

![การตั้งค่า → ช่องทาง ก่อนเชื่อมต่ออะไรเลย แต่ละช่องทางลิงก์แยกกัน และมีสถานะกับเวลาซิงค์ล่าสุดของตัวเอง](/screens/channels.th.png)

## สามแท็บ

**การตั้งค่า → ช่องทาง** มีสามแท็บ:

- **เพิ่มช่องทาง** — แค็ตตาล็อก ค้นหาตามชื่อ หรือกรองตามประเภท แล้วกด **เชื่อมต่อ**
  ช่องทางที่คุณใช้อยู่แล้วจะแสดง **เพิ่มบัญชีอื่น**
- **เชื่อมต่อแล้ว** — การเชื่อมต่อทั้งหมดของคุณ เปิดรายการหนึ่งเพื่อดูรายการที่พัก สถานะการซิงค์ และ
  สถานะการเปิดขาย
- **แอป** — แอปที่คุณอนุญาตให้เข้าถึงบัญชี เช่น Santi, ChatGPT หรือ Claude ดู
  [เชื่อมต่อผู้ช่วย AI](/th/help/ai-assistants/)

## การเชื่อมต่อและบัญชี

**การเชื่อมต่อ** หนึ่งรายการคือบัญชีช่องทางหนึ่งบัญชี คุณเชื่อมต่อได้:

- **บัญชี Airbnb** หลายบัญชีเข้ากับพื้นที่ทำงานเดียว — เป็นกรณีทั่วไปของผู้จัดการที่ถือรายการที่พักไว้ใต้บัญชีโฮสต์หลายบัญชี
- **ที่พัก Booking.com** หลายแห่ง แห่งละหนึ่ง Hotel ID
- ช่องทางอื่นใดก็ได้ในรายการ **ทีละหนึ่งที่พัก** — เชื่อมต่อช่องทางเดิมอีกครั้งสำหรับที่พักอื่น

แต่ละการเชื่อมต่อมีหน้าของตัวเองใน **การตั้งค่า → ช่องทาง** แสดงรายการที่พัก เวลาที่ซิงค์ล่าสุด
และทุกการกระทำที่ทำได้ ไม่มีส่วนใดใน Santara AI ที่ถือว่ามีอะไรเพียงหนึ่งเดียว

## สถานะของรายการที่พัก

รายการที่พักแต่ละรายการในหน้าการเชื่อมต่อมีป้ายกำกับอย่างใดอย่างหนึ่งต่อไปนี้:

| ป้ายกำกับ | ความหมาย |
| --- | --- |
| **ยังไม่ได้ลิงก์** | Santara AI เห็นรายการที่พักบนช่องทาง แต่ยังไม่ได้ชี้ไปยังห้องพักใดที่นี่ ไม่มีอะไรซิงค์ |
| **ลิงก์แล้ว — ยังไม่ได้จับคู่ราคา** | ชี้ไปยังห้องพักแล้ว แต่ราคายังไม่มีที่ปลายทาง |
| **ต้องดำเนินการ** | มีเรื่องที่ต้องให้คุณทำ — เหตุผลแสดงอยู่ข้าง ๆ เช่น *ยืนยันความจุเพื่อดำเนินการต่อ* |
| **พร้อม — ยังไม่เปิดขาย** | ตั้งค่าและจับคู่แล้ว แต่ช่องทางยังไม่ได้ส่งมอบการควบคุม |
| **กำลังเผยแพร่…** | กำลังเปิดขายอยู่ในขณะนี้ |
| **เปิดขายแล้ว** | ห้องว่างและราคาออกไป การจองและข้อความเข้ามา |
| **ข้อผิดพลาด** | ช่องทางปฏิเสธบางอย่าง เหตุผลแสดงอยู่ข้าง ๆ |

บน Airbnb การนำเข้ารายการที่พักจะเปิดขายเป็นขั้นตอนสุดท้าย บน Booking.com และช่องทางอื่นทั้งหมด
การจับคู่ห้องพักจะเปิดขายทันที ดู [การเปิดขาย](/th/channels/going-live/)

## เวลาในการซิงค์

- **การจองใหม่ การยกเลิก และข้อความ** เข้ามาภายในไม่กี่วินาทีถึงหนึ่งนาที โดยช่องทางเป็นฝ่ายส่งมา
- **การเปลี่ยนแปลงห้องว่างและราคาที่คุณทำ** ถูกส่งออกไปทันทีที่บันทึก ปกติเห็นบนช่องทางภายในหนึ่งนาที
- **การอ่านข้อมูลใหม่ทั้งหมด** ของการเชื่อมต่อเกิดขึ้นเมื่อคุณกด **รีเฟรช** และตามกำหนดเวลา

ถ้าช่องทางขัดข้อง การเปลี่ยนแปลงจะเข้าคิวรอและถูกส่งออกไปเมื่อช่องทางกลับมาทำงาน คุณไม่ต้องทำซ้ำ

## การยกเลิกการเชื่อมต่อมีผลอย่างไร

การยกเลิกการเชื่อมต่อจะหยุดการซิงค์ และนำการจอง แขก ข้อความ และรีวิวที่มาจากการเชื่อมต่อนั้นออก
**ไม่มีอะไรบนช่องทางได้รับผลกระทบ** — รายการที่พัก ปฏิทิน และการจองบนช่องทางยังอยู่ครบ คุณเชื่อมต่อบัญชีเดิมอีกครั้งภายหลังและนำเข้าใหม่ได้

การนำรายการที่พักรายการเดียวออก (**นำออกจาก Santara AI**) มีผลแบบเดียวกันกับห้องพักนั้นห้องเดียว

:::caution
การยกเลิกการเชื่อมต่อไม่ใช่วิธีหยุดชั่วคราว ถ้าคุณต้องการให้ช่องทางหยุดรับการจองสักระยะ ให้ปิดวันที่ใน
[ปฏิทิน](/th/daily/calendar/) แทน — วิธีนี้เก็บข้อมูลและประวัติของคุณไว้
:::
