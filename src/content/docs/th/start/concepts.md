คำถามแทบทุกข้อว่า "สิ่งนี้อยู่ตรงไหน?" ตอบได้ด้วยหกคำนี้ คุ้มค่าที่จะใช้เวลา
ห้านาที

## พื้นที่ทำงาน

ทุกอย่างที่คุณเห็นเป็นของ**พื้นที่ทำงาน**เดียว — ที่พัก ทีม การเรียกเก็บเงิน และเว็บไซต์จองตรง
ของคุณ ถ้าคุณดูแลพอร์ตโฟลิโอสองชุดที่ต้องไม่ปะปนกัน ก็คือสองพื้นที่ทำงาน และคุณ
สลับไปมาได้จากเมนูบัญชี

การเข้าสู่ระบบของคุณแยกจากพื้นที่ทำงาน คนเดียวกันเป็นเจ้าของในพื้นที่ทำงานของตัวเอง และเป็น
พนักงานทำความสะอาดในพื้นที่ทำงานของคนอื่นได้

## ที่พัก แล้วจึงห้อง

**ที่พัก**คืออาคารหรือที่อยู่หนึ่งแห่ง **ห้อง**คือหน่วยที่จองได้ภายในที่พักนั้น

| สิ่งที่คุณขาย | ที่พัก | ห้อง |
| --- | --- | --- |
| วิลล่าทั้งหลัง ประกาศเดียว | วิลล่า | หนึ่งห้อง — วิลล่าทั้งหลัง |
| วิลล่า 3 ห้องนอนที่ให้เช่าแยกห้อง | วิลล่า | สามห้อง |
| เกสต์เฮาส์เล็ก ๆ 8 ยูนิต | เกสต์เฮาส์ | แปดห้อง |
| อพาร์ตเมนต์ห้าห้องในตึกเดียว ขายแยกกัน | ปกติเป็นห้าที่พัก | แห่งละหนึ่งห้อง |

![พื้นที่ทำงานมีที่พัก ที่พักมีห้อง แต่ละห้องมีแผนราคาของตัวเองและจับคู่แบบหนึ่งต่อหนึ่งกับรายการที่พักบนช่องทาง](/diagrams/object-model.th.svg)

**ห้องคือสิ่งที่แขกจอง และห้องคือสิ่งที่ถูกเรียกเก็บเงิน** ราคา ห้องว่าง รูปภาพ
ความจุ และการจับคู่ช่องทาง ล้วนผูกอยู่กับห้อง ที่พักเก็บสิ่งที่ห้องใช้ร่วมกัน: ที่อยู่
Wi-Fi กฎของบ้าน กลุ่มงานทำความสะอาด

ข้อมูลบางอย่างมีอยู่ทั้งสองระดับ — Wi-Fi รหัสประตู หมายเหตุการเข้าถึง ตั้งไว้ที่ที่พักแล้ว
ทุกห้องจะรับค่าไป ตั้งไว้ที่ห้องแล้วค่าของห้องนั้นจะใช้แทน ดู
[ที่พักและห้อง](/th/setup/properties/)

## แผนราคา

**แผนราคา**คือราคาที่ห้องขาย บวกกับกฎที่ผูกอยู่: จำนวนคืนขั้นต่ำ
จำนวนแขกที่รวมอยู่ในราคา ค่าแขกเพิ่มต่อคน และเงื่อนไขการยกเลิก

ห้องหนึ่งมีแผนราคาได้มากกว่าหนึ่งแผน (เช่น ราคาแบบยืดหยุ่น และราคาแบบไม่คืนเงินที่ถูกกว่า)
ห้องที่นำเข้ามาจะมาพร้อมแผนราคาที่สร้างจากข้อมูลที่ช่องทางมีอยู่

ราคาต่อคืนบนปฏิทินคือราคาของแผนราคาสำหรับคืนนั้น กฎราคาเปลี่ยน
ตัวเลขนั้น แต่ไม่ได้สร้างแผนใหม่

## รายการที่พักและการเชื่อมต่อ

**การเชื่อมต่อ**คือบัญชีช่องทางหนึ่งบัญชีที่คุณเชื่อมไว้ — การเข้าสู่ระบบ Airbnb หนึ่งบัญชี หรือที่พักบน Booking.com
หนึ่งแห่ง คุณมีได้หลายการเชื่อมต่อ รวมถึงบัญชี Airbnb หลายบัญชี

**รายการที่พัก**คือสิ่งหนึ่งบนช่องทางนั้นที่จับคู่กับห้องหนึ่งห้องใน Santara AI การจับคู่เป็นแบบหนึ่งต่อหนึ่ง:
รายการที่พักนี้บน Airbnb คือห้องนั้น เมื่อจับคู่รายการที่พักแล้วและช่องทางทำงานอยู่ ห้องว่าง
และราคาของห้องนั้นจะส่งออกไป และการจองและข้อความจะส่งเข้ามา

ในหน้าของการเชื่อมต่อ แต่ละรายการที่พักจะมีป้ายอย่างใดอย่างหนึ่งต่อไปนี้:

| ป้าย | ความหมาย |
| --- | --- |
| **ยังไม่ได้ลิงก์** | เราเห็นรายการที่พัก แต่ยังไม่ได้ชี้ไปที่ห้องใด |
| **ลิงก์แล้ว — ยังไม่ได้จับคู่ราคา** | ชี้ไปที่ห้องแล้ว แต่ราคายังไม่มีที่ให้ส่งไป |
| **ต้องดำเนินการ** | มีบางอย่างต้องให้คุณจัดการ เช่น *ยืนยันความจุเพื่อดำเนินการต่อ* |
| **พร้อม — ยังไม่เปิดขาย** | ตั้งค่าแล้ว แต่ช่องทางยังไม่ส่งมอบการควบคุม |
| **กำลังเผยแพร่…** | กำลังเปิดขายอยู่ตอนนี้ |
| **เปิดขายแล้ว** | ห้องว่างและราคาซิงค์ออกไป การจองและข้อความซิงค์เข้ามา |
| **ข้อผิดพลาด** | ช่องทางปฏิเสธบางอย่าง เหตุผลแสดงอยู่ข้าง ๆ |

บน Airbnb การนำเข้ารายการที่พักจะเปิดขายเป็นขั้นตอนสุดท้าย รายการที่พักที่ Airbnb ยังไม่ยืนยัน
จะรออยู่ในสถานะ *พร้อม — ยังไม่เปิดขาย* จนกว่าคุณจะกด **เปิดขาย** บน Booking.com และช่องทางอื่นทั้งหมด
การจับคู่ห้องจะเปิดขายทันที ดู[การเปิดขาย](/th/channels/going-live/)

## การจอง แขก เธรด

**การจอง** (หรือเรียกว่าการเข้าพัก) เป็นของห้องหนึ่งและช่วงวันที่หนึ่งช่วง **แขก**คือ
บุคคลหนึ่งคน และคนเดียวกันที่เข้าพักสองครั้งคือแขกหนึ่งคนที่มีประวัติ **เธรด**คือ
บทสนทนากับแขกคนนั้น — หนึ่งเธรดต่อการจองหนึ่งครั้งบนช่องทางส่วนใหญ่

## ความสามารถ ไม่ใช่ตำแหน่งงาน

สิทธิ์การเข้าถึงไม่ใช่ "พนักงานทำความสะอาดเห็นสามหน้าจอ" ทุกหน้าจอและทุกเส้นทาง API จะขอ
**ความสามารถ (capability)** ที่มีชื่อกำกับ — `stay.read`, `pricing.write`, `guest.message.send` — และบทบาทของคุณคือชุดของ
ความสามารถเหล่านั้น ซึ่งจำกัดให้เฉพาะบางอาคารได้ นั่นคือเหตุผลที่พนักงานทำความสะอาดเห็นได้ว่างาน
อยู่ในอาคารไหน โดยไม่สามารถเปิดดูที่พักทั้งหมดของคุณได้ ดู[ทีมและบทบาท](/th/setup/team/)

## คำเกี่ยวกับเงิน

- **รายได้**ใน Santara AI หมายถึง**ยอดรับสุทธิ (net payout)** — เงินที่ช่องทางจ่ายให้คุณจริงหลังหัก
  ค่าคอมมิชชัน มีป้ายกำกับบนหน้าจอทุกที่ที่แสดง เพราะยอดรวมกับยอดรับสุทธิต่างกัน
  15% และถ้าสับสนกันจะทำให้รายงานทั้งปีเสีย
- **RevPAN** คือรายได้ต่อคืนที่มีให้ขาย: รายได้หารด้วยทุกคืนที่คุณมีให้ขาย
  เป็นตัวเลขที่ใช้วัดผลระบบตั้งราคา เพราะ ADR และอัตราการเข้าพักต่างก็ขยับไปเอง
  และไม่มีตัวใดตัวหนึ่งบอกได้ว่าคุณกำลังทำได้ดีหรือไม่
