คุณถูกเพิ่มเข้าพื้นที่ทำงานในฐานะ**โฮสต์ร่วม** ในทางปฏิบัติหมายความว่าคุณดูแลงานประจำวัน
ส่วนเจ้าของยังถือกุญแจเรื่องเงินและการตั้งค่า

ไม่มีบทบาท "ผู้จัดการที่พัก" แยกต่างหาก และคุณไม่จำเป็นต้องมี — โฮสต์ร่วมที่
[จำกัดให้เฉพาะบางอาคาร](/th/setup/team/#การจำกัดขอบเขตตามอาคาร) *ก็คือ*ผู้จัดการที่พัก

## ชั่วโมงแรกของคุณ

1. **เปิดลิงก์คำเชิญ** — จากอีเมล หรือจาก WhatsApp หรือ Zalo ลิงก์จะเปิดหน้าเดียว:
   ตั้งรหัสผ่านแล้วคุณก็เข้าใช้งานได้ หรือกรอกรหัสผ่านเดิมถ้าคุณมีบัญชีอยู่แล้ว
   ลิงก์ที่มาทางข้อความจะขอ**รหัส 6 หลัก**ที่เราส่งไปทางอีเมลด้วย ลิงก์มีอายุหนึ่งสัปดาห์ ดู
   [การเข้าใช้งาน](/th/start/invited-cleaner/#การเข้าใช้งาน) การเข้าสู่ระบบเป็นของคุณและใช้ได้กับทุก
   พื้นที่ทำงานที่คุณได้รับเชิญ
2. **ตั้งภาษาและเขตเวลาของคุณเอง** — [บัญชีของคุณ](/th/setup/account/#ภาษาและเขตเวลา)
   การตั้งค่าเหล่านี้ติดตัวคุณไป และแยกจากของพื้นที่ทำงาน
3. **อ่าน[Santara AI ประกอบขึ้นอย่างไร](/th/start/concepts/)** หกคำ — พื้นที่ทำงาน ที่พัก ห้อง
   แผนราคา รายการที่พัก การเชื่อมต่อ — แล้วทุกหน้าจอจะไม่ลึกลับอีกต่อไป
4. **เปิดวันนี้** สรุปประจำวันคืองานหลัก ที่เหลือคือที่ที่คุณไปเมื่อสรุปพา
   คุณไป

จากนั้นทำตาม[สัปดาห์แรกของคุณ](/th/start/first-week/) ซึ่งเป็นจังหวะการทำงานจริง

## สิ่งที่คุณทำได้

แทบจะทั้งหมดของงานประจำวัน:

| ด้าน | สิ่งที่คุณมี |
| --- | --- |
| **แขก** | อ่านและตอบทุกบทสนทนา ส่งข้อความ ตอบรีวิว |
| **การจอง** | สร้าง เปลี่ยน และยกเลิกการเข้าพัก ปิดและเปิดวันบนปฏิทิน |
| **งานทำความสะอาด** | ทั้งบอร์ด — มอบหมายงานทำความสะอาด ปิดงาน ดูแลกลุ่มงานทำความสะอาด |
| **ซ่อมบำรุง** | เปิด มอบหมาย และนัดเวลาใบงาน |
| **การเข้าถึง** | อ่าน*และตั้ง*รหัสประตู Wi-Fi และหมายเหตุการเข้าถึง |
| **บริการเสริม** | ดูโอกาสและส่งข้อเสนอ |
| **เงิน** | อ่านรายงาน ยอดรับ และรายงานสำหรับเจ้าของ และบันทึกค่าใช้จ่าย |
| **เจ้าของ** | ดูรายงานสำหรับเจ้าของ |
| **เทมเพลต** | เขียนและแก้ไขคำตอบถึงแขกที่บันทึกไว้ซึ่งทุกคนใช้ |

## สิ่งที่ยังเป็นของเจ้าของ

คุณจะพบว่าสิ่งเหล่านี้อ่านได้อย่างเดียว และเป็นความตั้งใจ ไม่ใช่การมองข้าม:

| คุณเห็นได้ | คุณเปลี่ยนไม่ได้ | เหตุผล |
| --- | --- | --- |
| อัตราและราคา | เผยแพร่ราคาหรือแก้ชุดกฎ | ราคาที่ผิดพลาดหนึ่งครั้งขายคืนจริงในราคาที่ผิด |
| การตั้งค่าพื้นที่ทำงาน | เวลาสรุป ภาษา สกุลเงิน น้ำเสียง | สิ่งเหล่านี้มีผลกับ*ทุกคน* — การเปลี่ยนคือการเปลี่ยนเวลาเช้าของทั้งทีม |
| รายชื่อทีม | เชิญคนหรือเปลี่ยนบทบาท | สิทธิ์การเข้าถึงเป็นของเจ้าของที่จะให้ |
| การเชื่อมต่อช่องทาง | เชื่อมต่อ ยกเลิกการเชื่อมต่อ หรือเปิดขาย | การมอบปฏิทินให้ช่องทางเป็นการตัดสินใจของเจ้าของ |
| การเรียกเก็บเงิน | แพ็กเกจหรือบัตร | เป็นเงินของเขา |

ถ้าคุณต้องการสิ่งใดในนี้ ขอให้เจ้าของทำให้ หรือย้ายคุณเป็น**โฮสต์ผู้ดูแล** — ซึ่งให้คุณ
ทุกอย่าง รวมถึงการเรียกเก็บเงิน ไม่มีขั้นกลางระหว่างสองบทบาทนี้ โดยตั้งใจ

:::note[ขอบเขตอาจจำกัดสิทธิ์ให้แคบลงอีก]
ถ้าเจ้าของจำกัดคุณไว้เฉพาะบางอาคาร ทุกอย่างข้างต้นใช้**เฉพาะกับอาคาร
เหล่านั้น** คุณจะไม่เห็นที่พักส่วนที่เหลือของเขาเลย — ทั้งปฏิทิน รายได้
และแขก ข้อความสรุปอย่าง *"3 อาคาร · 7 ห้อง"* บนหน้าจอทีมคือสิ่งที่คุณมี
:::

## ห้าเรื่องที่ควรทำในสัปดาห์แรก

1. **กรอกข้อมูลการเข้าพัก**ของทุกอาคารที่คุณดูแล — Wi-Fi รหัสประตู หมายเหตุการเข้าถึง
   เวลาเช็คอิน ข้อความถึงแขกและเว็บไซต์จองตรงต่างอ่านจากข้อมูลนี้ และคำถามของแขกครึ่งหนึ่ง
   ตอบได้ด้วยข้อมูลนี้ ดู
   [ข้อมูลการเข้าพัก](/th/setup/properties/#ข้อมูลการเข้าพัก-wifi-รหัสประตู-การเข้าที่พัก)
2. **ตั้งกลุ่มงานทำความสะอาด** เพื่อให้สรุปประจำวันเขียนข้อความ WhatsApp หนึ่งข้อความต่อพนักงานทำความสะอาดหนึ่งคน
   แทนที่จะเป็นหนึ่งข้อความต่อที่พัก — [กลุ่มงานทำความสะอาด](/th/daily/tasks/#กลุ่มงานทำความสะอาด)
3. **เขียนเทมเพลตข้อความ**ที่เจ้าของพิมพ์ซ้ำอยู่เรื่อย ๆ —
   [เทมเพลตข้อความ](/th/setup/message-templates/)
4. **เคลียร์รีวิวที่ค้าง** บน Airbnb รีวิวจะไม่ปรากฏจนกว่าทั้งสองฝ่ายจะเขียน ดังนั้น
   รีวิวจากแขกที่ยังไม่ได้เขียนตอบคือเงินที่ทิ้งไว้บนโต๊ะ —
   [รีวิว](/th/daily/reviews/)
5. **ไล่รายการบริการเสริมหนึ่งรอบ** เช็คเอาท์ช้าและคืนว่างคืนเดียวข้างการเข้าพักคือ
   รายได้ที่ได้มาง่ายที่สุดในธุรกิจนี้ — [บริการเสริม](/th/money/upsells/)

## การทำงานร่วมกับเจ้าของ

- **การแจ้งเตือนส่งตามว่าใครลงมือจัดการได้** ไม่ใช่ตามชื่อ คุณจะเริ่มได้รับ
  การแจ้งเตือนที่บทบาทของคุณรับผิดชอบ โดยไม่ต้องมีใครตั้งค่าให้ส่งมาที่คุณ
- **สรุปประจำวันเขียนด้วยภาษาของพื้นที่ทำงาน** ไม่ใช่ภาษาของคุณ ถ้าทีมอ่าน
  ภาษาอินโดนีเซียและคุณทำงานเป็นภาษาอังกฤษ นั่นคือผลที่ตั้งใจไว้ — หน้าจอของคุณยังเป็นภาษาอังกฤษ
- **ทุกอย่างที่คุณทำจะบันทึกว่าเป็นของคุณ** และยังคงบันทึกไว้หลังคุณออกไป นั่นปกป้อง
  คุณพอ ๆ กับปกป้องเขา

## ถ้าหน้าจอไม่ให้คุณเข้า

นั่นคือบทบาทของคุณ ไม่ใช่ข้อบกพร่อง ตรวจก่อนว่าคุณอยู่ในพื้นที่ทำงานที่ถูกต้อง — เมนูบัญชี
บอกว่าอยู่ที่ไหน จากนั้นถามเจ้าของ มีแต่เขาเท่านั้นที่ขยายสิทธิ์ได้ ดู
[ทีมและบทบาท](/th/setup/team/)
