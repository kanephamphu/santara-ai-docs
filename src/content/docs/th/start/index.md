Santara AI คือซอฟต์แวร์จัดการงานสำหรับที่พักให้เช่าระยะสั้น คุณเชื่อมต่อช่องทางที่ขายอยู่แล้ว
— Airbnb, Booking.com และเว็บไซต์จองของคุณเอง — จากนั้นคุณจะมีปฏิทินเดียว กล่องข้อความเดียว
ตารางทำความสะอาดเดียว และบัญชีชุดเดียว แทนที่จะเปิดเบราว์เซอร์ค้างไว้หกแท็บ

Santara AI ไม่ใช่เว็บไซต์ลงประกาศที่พัก แขกจะไม่จอง
"ผ่าน Santara AI" เว้นแต่คุณเผยแพร่[เว็บไซต์จองตรง](/th/setup/booking-site/) ของคุณเอง ซึ่ง
เป็นของคุณและเงินเข้าบัญชี Stripe ของคุณเอง

## สิ่งที่มาแทน

| แทนที่จะ | คุณได้ |
| --- | --- |
| เช็ก extranet สามแห่งทุกเช้า | **[วันนี้](/th/daily/)** — แขกเข้า แขกออก และเรื่องที่ต้องตัดสินใจ เขียนสรุปไว้ให้ |
| คัดลอกวันที่ระหว่างปฏิทิน | **[ปฏิทินเดียว](/th/daily/calendar/)** — ทุกคืน ทุกห้อง ส่งไปทุกช่องทาง |
| กล่องข้อความสองที่ | **[ข้อความ](/th/daily/messages/)** — หนึ่งเธรดต่อแขกหนึ่งคน บน Airbnb, Booking.com และ Expedia คำตอบของคุณส่งกลับไปทางช่องทางที่แขกจอง |
| กลุ่ม WhatsApp สำหรับงานทำความสะอาด | **[งาน](/th/daily/tasks/)** — งานเปลี่ยนแขกสร้างให้อัตโนมัติในคืนก่อนเช็คเอาท์ |
| แก้ราคาด้วยมือทุกวันอาทิตย์ | **[ตั้งราคาอัจฉริยะ](/th/money/pricing/)** — กฎที่ปรับราคาต่อคืนตามฤดูกาล ระยะเวลาจองล่วงหน้า และอัตราการเข้าพัก |
| สเปรดชีตหนึ่งไฟล์ต่อเจ้าของหนึ่งราย | **[รายงาน](/th/money/reports/)** — รายได้เข้า ค่าใช้จ่ายออก รายงานสำหรับเจ้าของ |

## อะไรที่เป็นอัตโนมัติจริง ๆ

Santara AI ระมัดระวังเรื่องนี้ เพราะซอฟต์แวร์ที่ทำอะไรกับรายการที่พักที่เปิดขายอยู่โดยไม่มีใครสั่ง
คือสาเหตุที่โฮสต์เสียการจอง:

- **งานเปลี่ยนแขก** ปรากฏขึ้นเองในคืนก่อนเช็คเอาท์แต่ละครั้ง
- **การจอง แขก ข้อความ และรีวิว** ซิงค์จากทุกช่องทางที่เชื่อมต่อ
- **ราคา** ที่คำนวณจากกฎราคาของคุณจะเผยแพร่ไปยังช่องทาง
- **โอกาสขายบริการเสริม** — เช็คเอาท์ช้า ต่ออีกหนึ่งคืน มาถึงก่อนเวลา — ระบบมองเห็นจาก
  ปฏิทินและเสนอให้คุณเป็นฉบับร่าง
- **สรุปประจำวัน** เขียนให้คุณทุกเช้าในภาษาของคุณ

และอะไรที่ไม่ใช่:

- **ปฏิทินของคุณไม่ถูกยึดไปเมื่อคุณนำเข้ารายการที่พัก** การนำเข้าแค่อ่านรายการที่พักของคุณ
  ไม่เปลี่ยนอะไรบนช่องทาง การควบคุมจะย้ายมาก็ต่อเมื่อคุณกด **เปิดขาย** เท่านั้น ดู
  [การเปิดขาย](/th/channels/going-live/)
- **ราคาที่คุณพิมพ์เองจะคงอยู่** เว้นแต่คุณอนุญาตให้ระบบตั้งราคาเขียนทับอย่างชัดเจน
- **ไม่มีอะไรส่งถึงแขกโดยไม่ผ่านคุณ** — เว้นแต่คุณเปิด
  [ตอบกลับอัตโนมัติ](/th/daily/messages/#ตอบกลับอัตโนมัติ) ซึ่งตอบเฉพาะหัวข้อที่คุณอนุญาต และปล่อย
  เรื่องเงิน วันที่ การร้องเรียน และเหตุฉุกเฉินไว้ให้คุณเสมอ นอกจากนั้นผู้ช่วยและเครื่องมือข้อความ
  จะร่างไว้ คุณเป็นคนส่ง

## เหมาะกับใคร

ตั้งแต่โฮสต์ที่มีวิลล่าหลังเดียวไปจนถึงผู้ประกอบการที่ดูแลหลายร้อยยูนิต หน้าจอเหมือนกัน สิ่งที่
ต่างคือใครเห็นอะไร — ดู[ทีมและบทบาท](/th/setup/team/) พนักงานทำความสะอาดเห็นแค่งานของตัวเอง
และไม่มีอะไรอื่น เจ้าของเห็นรายงาน ไม่ใช่กล่องข้อความของคุณ

:::tip[ตั้งค่าตามลำดับที่ผลิตภัณฑ์แนะนำ]
[รายการตรวจสอบการตั้งค่า](/th/start/quickstart/) ที่ด้านบนของพื้นที่ทำงานมีสามขั้นตอน —
เชื่อมต่อช่องทาง นำเข้ารายการที่พัก ตรวจราคาและรายละเอียด ทำตามลำดับแล้วข้อมูลจะเข้ามาถูกต้อง
ตั้งแต่ครั้งแรก และไม่มีอะไรต้องแก้ทีหลัง
:::
