**การตั้งค่า** เป็นหน้าเดียวที่มีหลายแท็บ และทุกแท็บในหน้านี้เป็นของ **พื้นที่ทำงาน** ที่ทุกคนใช้ร่วมกัน
บัญชีของคุณเองตั้งใจไม่ให้อยู่ในนั้น — บัญชีอยู่หลังเมนูบัญชีที่ด้านล่างของแถบด้านข้าง เพราะนั่นคือที่ที่
คนจะมองหารหัสผ่านของตัวเอง ดู [บัญชีและความปลอดภัยของคุณ](/th/setup/account/)

| แท็บ | ขอบเขต |
| --- | --- |
| **พื้นที่ทำงาน** | ใช้ร่วมกัน — ชื่อ ภาษา เขตเวลา สกุลเงิน |
| **เว็บไซต์จองตรง** | ใช้ร่วมกัน — [เว็บไซต์จองตรงของคุณ](/th/setup/booking-site/) |
| **ช่องทาง** | ใช้ร่วมกัน — [การเชื่อมต่อช่องทาง](/th/channels/) |
| **เทมเพลตข้อความ** | ใช้ร่วมกัน — คำตอบถึงแขกที่บันทึกไว้ |
| **ทีม** | ใช้ร่วมกัน — [ผู้คนและบทบาท](/th/setup/team/) |
| **การเรียกเก็บเงิน** | ใช้ร่วมกัน — [แพ็กเกจและใบแจ้งหนี้](/th/setup/billing/) |

## ภาษา

อินเทอร์เฟซของ Santara AI มีให้ใช้เป็น **English, Bahasa Indonesia, Tiếng Việt และ ไทย**

- การตั้งค่าภาษา **ของคุณ** เปลี่ยนอินเทอร์เฟซสำหรับคุณ
- ภาษา **ของพื้นที่ทำงาน** กำหนดว่า [สรุปประจำวัน](/th/daily/) จะเขียนเป็นภาษาใด และเป็นภาษา
  เริ่มต้นของทุกสิ่งที่พื้นที่ทำงานสร้างขึ้นสำหรับกลุ่ม

สองอย่างนี้แยกกันโดยตั้งใจ: ผู้จัดการที่พูดภาษาเวียดนามทำงานเป็นภาษาเวียดนามได้ ในพื้นที่ทำงานที่ส่ง
สรุปประจำวันเป็นภาษาอินโดนีเซียให้ทีมทำความสะอาด

## เขตเวลา

เขตเวลาของพื้นที่ทำงานกำหนดว่า "วันนี้" หมายถึงอะไร — สำหรับการเข้าพัก การทำความสะอาด สรุปประจำวัน
และทุกวันที่ในทุกรายงาน ตั้งตามที่ตั้งของที่พัก ไม่ใช่ตามที่ที่คุณอยู่

## สกุลเงิน

สกุลเงินของพื้นที่ทำงานคือสกุลเงินที่ใช้แสดงตัวเลข [เว็บไซต์จองตรง](/th/setup/booking-site/) ของคุณ
มีการตั้งค่าสกุลเงินของตัวเองสำหรับสิ่งที่แขกเห็น

## การตั้งค่าการปฏิบัติงาน

แท็บพื้นที่ทำงานมีการตั้งค่าที่เปลี่ยนวิธีที่ผลิตภัณฑ์ทำงานสำหรับทุกคนในพื้นที่ทำงานนั้น:

| การตั้งค่า | ทำอะไร |
| --- | --- |
| **เวลาสรุปประจำวัน** | เวลาที่ [สรุปประจำวัน](/th/daily/) ถูกสร้างขึ้นในแต่ละวัน |
| **ภาษาของสรุปประจำวัน** | เขียนเป็นภาษาใด — แยกจากภาษาของอินเทอร์เฟซ |
| **เขตเวลาของพื้นที่ทำงาน** | "วันนี้" หมายถึงอะไร ในทุกที่ |
| **สกุลเงินที่แสดง** | สกุลเงินที่ใช้แสดงตัวเลข |
| **น้ำเสียงข้อความเริ่มต้น** | น้ำเสียงตั้งต้นของร่างคำตอบถึงแขก |
| **มูลค่าบริการเสริมขั้นต่ำ** | โอกาสที่ต่ำกว่าค่านี้จะไม่ถูกแสดง รายการโอกาสจึงยังน่าอ่าน |
| **เปิดสรุปประจำวันก่อน** | เริ่มแอปที่สรุปประจำวันแทนแดชบอร์ด |
| **แจ้งเตือนการเข้าพักวันเดียวกัน** | ส่งอีเมลถึงทีมเมื่อมีการจองสำหรับการเข้าพักที่เช็คอินวันนี้ — เปิดอยู่โดยค่าเริ่มต้น |
| **ช่องทางการแจ้งเตือน** | ปัจจุบันคือแดชบอร์ด อีเมลและ SMS ยังไม่ได้เชื่อมต่อ |

### แจ้งเตือนการเข้าพักวันเดียวกัน

การจองสำหรับ **วันนี้** คือการจองที่อาจมีปัญหาได้: ห้องอาจทำความสะอาดไม่ทัน เมื่อมีการสร้าง — หรือ
ยกเลิก — การจองสำหรับการเข้าพักที่เช็คอินวันนี้ (ตามเขตเวลาของพื้นที่ทำงาน) อีเมลจะถูกส่งออกไปทันที
ไม่ว่าการจองจะมาจากช่องทาง จากเว็บไซต์จองตรงของคุณ หรือถูกป้อนเอง

- **ผู้จัดการและโฮสต์ร่วม** ได้รับ **เช็คอินวันนี้** (หรือ **ยกเลิกวันนี้**) พร้อมข้อมูลการเข้าพัก
  ข้อมูลติดต่อของแขก ยอดเงิน และช่วงเวลาทำความสะอาด หากการทำความสะอาดจะเสร็จช้า อีเมลจะบอกไว้
  และขอให้ตัดสินใจ
- **พนักงานทำความสะอาดของห้องนั้น** ได้รับ **ทำความสะอาดวันนี้** (หรือ **ยกเลิกงานทำความสะอาด**)
  พร้อมใบสั่งงาน
- คนที่ป้อนการจองจะไม่ได้รับอีเมลเกี่ยวกับการจองของตัวเอง

การเปลี่ยนวันที่ไม่ส่งอีเมล แต่จะแสดงใน [กระดิ่ง](#การแจ้งเตือน) มีเพียงเจ้าของพื้นที่ทำงานหรือ
ผู้ดูแลเท่านั้นที่ปิดการแจ้งเตือนนี้ได้

นอกจากนี้ยังมี **ชื่อและรูปประจำตัว** ของพื้นที่ทำงาน — โลโก้ที่แสดงในแถบด้านข้างและตัวสลับพื้นที่ทำงาน
ซึ่งทำให้สองพื้นที่ทำงานไม่ดูเหมือนกันเมื่อมองผ่านๆ

## การแจ้งเตือน

กระดิ่งที่ส่วนหัว การแจ้งเตือนส่งตาม **ผู้ที่ลงมือจัดการได้** ไม่ใช่ตามชื่อ เพราะฉะนั้นผู้จัดการที่ถูกเพิ่ม
เข้ามาเดือนหน้าจะได้รับการแจ้งเตือนที่ตั้งใจไว้สำหรับบทบาทของเขาทันที — ไม่ต้องชี้อะไรมาที่เขาใหม่

มีสิบประเภท: การจอง **ถูกสร้าง** **ถูกเปลี่ยน** หรือ **ถูกยกเลิก** งานทำความสะอาด **ถูกมอบหมาย**
ให้คุณหรือ **เสร็จแล้ว** ใบงาน **ถูกเปิด** **ถูกมอบหมาย** ให้คุณ หรือ **เสร็จแล้ว** **เชื่อมต่อช่องทางแล้ว**
ซึ่งระบุช่องทาง ที่พัก และจำนวนห้องที่จับคู่ และ **คำขอจากแขก** จาก
[คู่มือที่พักสำหรับแขก](/th/setup/guidebook/#เมื่อแขกขอบริการเสริม) ซึ่งระบุแขก บริการเสริม
ราคา และห้อง สิ่งอื่นทั้งหมดที่ผลิตภัณฑ์รู้จะอยู่บนหน้าจอ ไม่ได้อยู่ในกระดิ่ง โดยตั้งใจ —
รายการแจ้งเตือนที่รายงานสิ่งที่คุณจัดการไม่ได้จะไม่มีใครอ่านอีก

:::note[การซิงค์ครั้งแรกเงียบโดยตั้งใจ]
การเชื่อมต่อช่องทางจะนำเข้าประวัติการจองของคุณ บางครั้งย้อนหลังเป็นปี การจองเหล่านั้นไม่ใช่การจองใหม่
และคุณจะไม่ได้รับการแจ้งเตือน — มีเพียงสิ่งที่เกิดขึ้นหลังจากคุณเชื่อมต่อเท่านั้น
:::

## เทมเพลตข้อความ

คำตอบที่บันทึกไว้พร้อมตัวยึดตำแหน่งที่เติมค่าเองจากการเข้าพัก — ชื่อแขก เวลาเช็คอิน รหัสผ่าน wifi
รหัสประตู ยอดที่ต้องชำระ ใช้ร่วมกันทั้งพื้นที่ทำงาน คำตอบที่ทีมตกลงกันไว้จึงเป็นคำตอบที่ทุกคนส่ง

วิธีเขียน การดูตัวอย่างกับการจองจริง และเทมเพลตห้าแบบที่มีให้ตั้งแต่เริ่มต้น:
**[เทมเพลตข้อความ](/th/setup/message-templates/)**

## การสลับพื้นที่ทำงาน

เมนูบัญชีแสดงทุกพื้นที่ทำงานที่คุณเป็นสมาชิก แต่ละพื้นที่ทำงานมีที่พัก ทีม การเรียกเก็บเงิน และ
เว็บไซต์จองตรงของตัวเอง ไม่มีอะไรถูกแชร์ระหว่างกัน
