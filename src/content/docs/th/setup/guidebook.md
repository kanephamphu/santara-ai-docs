พิมพ์สติกเกอร์ QR ห้องละหนึ่งแผ่น แขกสแกนด้วยกล้องโทรศัพท์แล้วจะได้หน้าเกี่ยวกับการเข้าพักของเขา
ในภาษาของเขาเอง: เวลาเช็คอินและเช็คเอาท์ ชื่อเครือข่าย Wi-Fi กฎของที่พัก สิ่งอำนวยความสะดวก
สถานที่ที่คุณแนะนำ แผนที่ และบริการเสริมที่คุณขาย เมื่อแขกใส่รหัสการจอง หน้าเดียวกันนี้จะแสดง
**รหัสประตู** **รหัสผ่าน Wi-Fi** และ **วิธีเข้าที่พัก**

แขกไม่ต้องติดตั้งอะไร และไม่ต้องสร้างบัญชี

เปิดได้จาก **ที่พัก** เลือกที่พัก แล้วกด **ตั้งค่าคู่มือที่พัก** บนการ์ด **คู่มือที่พักสำหรับแขก**
หน้าของแต่ละห้องก็มีการ์ดเดียวกันนี้ พร้อมปุ่ม **จัดการสติกเกอร์**

## แขกเห็นอะไร

หน้านี้มีสองระดับ และความต่างระหว่างสองระดับคือหัวใจของการออกแบบทั้งหมด

![หน้าสำหรับแขกที่เปิดจากสติกเกอร์ในห้อง ก่อนยืนยัน: ข้อมูลการเข้าพัก กฎ และช่องสำหรับใส่รหัสการจอง](/screens/guidebook-guest.th.png)

| ทุกคนที่สแกนสติกเกอร์ | เฉพาะแขกที่ยืนยันการจองแล้ว |
| --- | --- |
| เวลาเช็คอินและเช็คเอาท์ | รหัสประตู |
| ชื่อเครือข่าย Wi-Fi | รหัสผ่าน Wi-Fi |
| กฎของที่พัก ที่จอดรถ สัตว์เลี้ยง | ขั้นตอนเช็คอิน ("วิธีเข้าที่พัก") |
| สิ่งอำนวยความสะดวกของห้อง | ราคาบริการเสริม และปุ่ม **ส่งคำขอ** |
| สถานที่ใกล้เคียงและแผนที่ | คำทักทายพร้อมชื่อและวันที่เข้าพักของแขก |
| บริการเสริมที่คุณมีให้ | |
| ลิงก์ไปยัง [เว็บไซต์จองตรง](/th/setup/booking-site/) ของคุณ หากเผยแพร่แล้ว | |

:::caution[สติกเกอร์คือลิงก์สาธารณะ]
ใครก็ตามที่ถ่ายรูปสติกเกอร์ได้ก็มีลิงก์นั้น — แขกคนก่อน คนส่งของ คนที่เดินผ่านหน้าประตู
นี่คือเหตุผลที่ไม่มีอะไรที่เปิดประตูได้เข้าถึงได้จากลิงก์เพียงอย่างเดียว หากสติกเกอร์หายหรือไปอยู่ในที่
ที่ไม่ควรอยู่ ให้ [เปลี่ยนรหัส](#สติกเกอร์-qr): สติกเกอร์ที่พิมพ์ไว้จะใช้ไม่ได้ทันที
:::

หน้านี้เปิดในภาษาของเบราว์เซอร์แขก — อังกฤษ อินโดนีเซีย เวียดนาม หรือไทย — และมีตัวเลือกภาษาอยู่
ด้านบน หน้านี้ไม่แสดงในเครื่องมือค้นหา

ทุกอย่างบนหน้ามาจากสิ่งที่คุณกรอกไว้แล้ว: เวลา Wi-Fi และรหัสจาก
[ข้อมูลการเข้าพัก](/th/setup/properties/#ข้อมูลการเข้าพัก-wifi-รหัสประตู-การเข้าที่พัก) สิ่งอำนวยความสะดวก
จากห้อง และบริการเสริมจาก [การตั้งค่าบริการเสริม](/th/money/upsells/)

## แขกยืนยันการจองอย่างไร

แขกพิมพ์ **รหัสการจอง** จากอีเมลยืนยันการจอง — ไม่ต้องใช้อะไรอื่น ช่องว่าง ขีด และตัวพิมพ์ใหญ่
ไม่มีผล รหัสที่สั้นกว่าหกตัวอักษรจะไม่ถูกจับคู่เลย

![หน้าเดียวกันหลังใส่รหัสการจอง: คำทักทาย รหัสประตู (ซ่อนไว้จนกว่าจะแตะ) และรหัสผ่าน Wi-Fi](/screens/guidebook-verified.th.png)

จากนั้นสิทธิ์การเข้าถึงจะเป็นไปตามการเข้าพัก ตามเขตเวลาของที่พักนั้น:

- **เปิดหนึ่งวันก่อนวันเข้าพัก** และ **ปิดเมื่อสิ้นวันเช็คเอาท์**
- การจองที่ **ถูกยกเลิก** จะเสียสิทธิ์ทันที แม้บนโทรศัพท์ที่กำลังแสดงรหัสอยู่
- สติกเกอร์ในห้องรับการจองของห้องนั้น และการจองในอาคารที่ยังไม่ได้ผูกกับห้องใด ส่วนสติกเกอร์ของ
  อาคารรับการจองใดก็ได้ในอาคาร
- แขกที่ตรวจสอบเร็วเกินไปจะได้รับแจ้งวันที่ข้อมูลของเขาจะเปิด แทนที่จะบอกว่าไม่พบการจอง
  การตรวจสอบก่อนเวลาไม่นับรวมในขีดจำกัดการใส่ผิด

หลังจากใส่ผิดห้าครั้งบนโทรศัพท์เครื่องเดียวกัน คู่มือจะให้แขกคนนั้นรอ 15 นาที ขีดจำกัดนับแยกต่อ
โทรศัพท์ แขกที่ใช้ Wi-Fi ของอาคารร่วมกันจึงไม่ล็อกกันเอง — มีเพียงการใส่ผิดติดต่อกันจากโทรศัพท์หลาย
เครื่องบนการเชื่อมต่อเดียวเท่านั้นที่จะหยุดการเชื่อมต่อนั้นไว้สำหรับทุกคน **ไม่ใช่คุณใช่ไหม ออกจากระบบ**
ล้างข้อมูลออกจากโทรศัพท์เครื่องนั้น สำหรับอุปกรณ์ที่ใช้ร่วมกัน หรือเมื่อแขกคืนเครื่อง

:::note[การจองที่ไม่มีรหัสจากช่องทาง]
แขกยืนยันได้เฉพาะการจองที่มีรหัสยืนยันจากช่องทาง การเข้าพักที่คุณสร้างเองไม่มีรหัสให้แขกพิมพ์
แขกเหล่านั้นจึงเห็นส่วนสาธารณะของคู่มือ แต่ปลดล็อกรหัสประตูจากตรงนั้นไม่ได้ — ส่งรหัสทางข้อความ
อย่างที่คุณทำอยู่
:::

## สติกเกอร์ QR

แต่ละอาคารมีสติกเกอร์หนึ่งแผ่นสำหรับทั้งอาคาร — ล็อบบี้ ประตูทางเข้า เคาน์เตอร์ต้อนรับ — บวกห้องละ
หนึ่งแผ่น สติกเกอร์ถูกสร้างขึ้นครั้งแรกที่คุณเปิดหน้าคู่มือที่พัก

ช่องสติกเกอร์แต่ละช่องแสดงคิวอาร์โค้ด รหัสของสติกเกอร์ จำนวนครั้งที่ถูกสแกนใน 30 วันที่ผ่านมา
และการกระทำสามอย่าง:

| การกระทำ | ทำอะไร |
| --- | --- |
| **เปิด / ปิด** | ปิดแล้วสติกเกอร์นั้นจะแสดง "ไม่พร้อมใช้งาน" จนกว่าคุณจะเปิดกลับ ไม่ต้องพิมพ์ใหม่ |
| **คัดลอกลิงก์** / **เปิดคู่มือ** | หน้าเดียวกันโดยไม่ต้องสแกน — สำหรับส่งในข้อความ หรือตรวจดูว่าแขกเห็นอะไร |
| **เปลี่ยนรหัส** | ให้รหัสใหม่แก่สติกเกอร์ **สติกเกอร์ที่พิมพ์ไว้จะใช้ไม่ได้ทันที** และคุณต้องพิมพ์แผ่นใหม่ |

### การพิมพ์

**พิมพ์สติกเกอร์ QR** จัดวางสติกเกอร์ทุกแผ่นที่เปิดอยู่ลงบนกระดาษ A4 แถวละสามแผ่น แต่ละแผ่นมีชื่อ
ที่พักและชื่อห้อง และข้อความ "สแกนเพื่อดูคู่มือที่พักและ Wi-Fi" เป็นภาษาอังกฤษ เวียดนาม และ
อินโดนีเซีย — หรือภาษาอังกฤษและไทยสำหรับที่พักในประเทศไทย — พิมพ์ครั้งเดียวจึงใช้ได้กับแขกทุกคน
พิมพ์ที่ **สเกล 100%** ตัดตามเส้นประ แล้วติดแต่ละแผ่นในห้องของมัน

สติกเกอร์ทุกแผ่นดาวน์โหลดเป็น **SVG** ได้ด้วย ซึ่งเป็นไฟล์ที่ร้านพิมพ์ต้องการสำหรับทำฉลากหรือ
ป้ายตั้งโต๊ะอะคริลิก

## สถานที่ใกล้เคียง

รายการ **สถานที่ใกล้เคียง** คือคำแนะนำของคุณเอง: ร้านอาหาร สถานที่ท่องเที่ยว ร้านขายยา สถานี
ที่ใกล้ที่สุด

- **เพิ่มสถานที่** — ชื่อ หมวดหมู่ (กินและดื่ม สถานที่ท่องเที่ยว กิจกรรม ช้อปปิ้ง การเดินทาง สิ่งจำเป็น)
  คำแนะนำสำหรับแขก ที่อยู่ และลิงก์แผนที่ (ไม่บังคับ) สถานที่จะถูกเผยแพร่ทันที
- **ร่างด้วย AI** — แนะนำสถานที่ที่มีชื่อเสียงใกล้ที่อยู่ของอาคารได้สูงสุดสิบสองแห่ง สถานที่เหล่านี้
  ถูกบันทึกเป็น **ฉบับร่าง** ซึ่งแขกไม่มีทางเห็น เปิดดูแต่ละแห่งบนแผนที่ก่อนเผยแพร่: AI อาจเข้าใจ
  สถานที่ผิดได้ และลิงก์แผนที่เป็นการค้นหา สถานที่ที่ไม่มีอยู่จริงจึงเห็นได้ชัด ที่พักต้องมีที่อยู่
  จึงจะใช้ฟีเจอร์นี้ได้
- **เผยแพร่ / ยกเลิกการเผยแพร่** เลื่อนขึ้นลง แก้ไข ลบ การแก้ไขชื่อหรือคำแนะนำจะลบคำแปลที่บันทึกไว้
  ของสถานที่นั้น แขกจึงไม่มีทางอ่านคำแปลของถ้อยคำที่คุณเปลี่ยนไปแล้ว
- **แปลสำหรับแขก** — เลือกภาษาที่คุณใช้เขียนสถานที่ แล้วสถานที่ที่เผยแพร่แล้วจะถูกแปลเป็นภาษาอื่นที่เหลือ
  คำแปลที่มีอยู่แล้วจะถูกเก็บไว้

อาคารหนึ่งมีสถานที่ได้สูงสุด 60 แห่ง

แขกเห็นแต่ละสถานที่พร้อมประเภท — ไอคอนและป้ายกำกับสี — และกรองรายการตามประเภทได้ บนโทรศัพท์
แต่ละสถานที่เป็นแถวกะทัดรัดหนึ่งแถว พร้อมปุ่ม **แผนที่**

![สถานที่ใกล้เคียงบนโทรศัพท์ของแขก กรองตามประเภท ในภาษาของแขก](/screens/guidebook-places-phone.th.png)

## สิ่งที่แขกเห็น: การตั้งค่า

แผง **สิ่งที่แขกเห็น** บนหน้าเดียวกัน แยกตามอาคาร:

- **เปิดคู่มือที่พักสำหรับอาคารนี้** — ปิดแล้วสติกเกอร์ทุกแผ่นในอาคารจะแสดง "ไม่พร้อมใช้งาน"
  โดยไม่ต้องเปลี่ยนรหัสใดๆ
- **ข้อความต้อนรับ** — หนึ่งข้อความต่อภาษา (EN, ID, VI, TH) เว้นว่างภาษาใดไว้เพื่อใช้ข้อความต้อนรับ
  มาตรฐาน
- **ส่วนต่างๆ** — ปิดสิ่งอำนวยความสะดวก กฎของที่พัก ที่จอดรถ และสัตว์เลี้ยง แผนที่และเส้นทาง
  สถานที่ใกล้เคียง หรือข้อเสนอ
- **แสดงรหัสประตู รหัสผ่าน Wi-Fi และขั้นตอนเช็คอินแก่แขกที่ยืนยันตัวตนแล้ว** — ปิดตัวเลือกนี้แล้ว
  คู่มือจะไม่แสดงข้อมูลการเข้าที่พักเลย แม้กับแขกที่ยืนยันแล้ว

กด **บันทึก** ระบบจะบันทึกเฉพาะสิ่งที่คุณเปลี่ยน

## เมื่อแขกขอบริการเสริม

แขกที่ยืนยันแล้วจะเห็นบริการเสริมที่คุณเปิดไว้ใน **บริการเสริม → การตั้งค่า** — เช็คอินก่อนเวลา
เช็คเอาท์ล่าช้า พักเพิ่มอีก 1 คืน — ในราคาเดียวกับที่การตั้งค่านั้นคำนวณให้การเข้าพักครั้งนั้นทุกประการ

บริการเสริมจะถูกเสนอเมื่อปฏิทินเอื้ออำนวยเท่านั้น:

| บริการเสริม | ต้องมี |
| --- | --- |
| **เช็คอินก่อนเวลา** | คืนก่อนวันเข้าพักว่าง และยังไม่เลยวันเข้าพัก |
| **เช็คเอาท์ล่าช้า** | ไม่มีใครพักในห้องในคืนของวันเช็คเอาท์ |
| **พักเพิ่มอีก 1 คืน** | เช่นเดียวกัน — คืนถัดจากการเข้าพักว่าง |

คืนที่คุณปิดไว้บนปฏิทินนับว่าไม่ว่าง กรณีอื่นจะแสดงว่า "ไม่ว่างในวันที่ของคุณ"

เมื่อแขกกด **ส่งคำขอ**:

1. คำขอจะปรากฏบนหน้า **บริการเสริม** เป็น **ตอบรับแล้ว** ในราคาที่แขกเห็น
2. ทุกคนที่ดูแลห้องนั้นได้จะได้รับการแจ้งเตือนใน [กระดิ่ง](/th/setup/workspace/#การแจ้งเตือน)
3. **การจองไม่ถูกเปลี่ยนแปลงใดๆ** ยืนยันกับแขกก่อน แล้วขยายหรือปรับการเข้าพักใน
   [การจอง](/th/daily/bookings/#การยกเลิกและการเปลี่ยนแปลง) เหมือนการเปลี่ยนแปลงอื่นๆ

แขกขอบริการเสริมแต่ละอย่างได้ครั้งเดียวต่อการเข้าพัก หากคุณปฏิเสธบนหน้าบริการเสริม คำขอนั้นจะยังคง
ถูกปฏิเสธ

## ตัวเลข

ด้านบนของหน้าคู่มือที่พักนับย้อนหลัง 30 วัน:

| ตัวเลข | นับอะไร |

## ใครเปลี่ยนแปลงได้

การดูหน้าคู่มือที่พักต้องมีสิทธิ์เข้าถึงที่พัก การเปลี่ยนสติกเกอร์ สถานที่ หรือการตั้งค่า ต้องมีสิทธิ์แก้ไข
ที่พัก **และ** สิทธิ์เข้าถึงทั้งอาคาร — เพื่อนร่วมทีมที่ได้รับเพียงห้องเดียวในอาคารดูได้ แต่เปลี่ยน
สิ่งที่แขกของทุกห้องเห็นไม่ได้ ดู [ทีมและบทบาท](/th/setup/team/)
