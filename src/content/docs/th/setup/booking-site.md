ทุกพื้นที่ทำงานเผยแพร่เว็บไซต์จองตรงได้ เงินเข้าบัญชี Stripe ของคุณ ไม่ใช่ของเรา

**เว็บไซต์จองตรง** ในแถบด้านข้าง ด้านซ้ายคือการตั้งค่า ด้านขวาคือตัวอย่างแบบสด

![ตัวสร้างเว็บไซต์จองตรง: การตั้งค่าด้านซ้าย ตัวอย่างแบบสดด้านขวา](/screens/booking-site.th.png)

## 1. เลือกซับโดเมน

ตัวพิมพ์เล็ก ตัวเลข และขีดกลาง นี่คือสิ่งที่แขกจะพิมพ์ จึงควรใช้ชื่อธุรกิจของคุณ บันทึกรายละเอียดเว็บไซต์
แล้วตัวอย่างจะเริ่มทำงาน

## 2. เลือกรูปลักษณ์

**เทมเพลต** กำหนดหน้าตาของแต่ละส่วน คุณกำหนดว่าจะแสดงส่วนใดและเรียงลำดับอย่างไร เลือกเทมเพลตและสีเน้น
อัปโหลดโลโก้ (PNG, JPG, WEBP หรือ GIF ขนาดไม่เกิน 5 MB หรือ URL รูปภาพสาธารณะ) และตั้งสกุลเงินที่ใช้แสดงราคา

## 3. สร้างหน้าแรก

ลากส่วนต่าง ๆ ให้เรียงตามที่ต้องการ หรือซ่อนส่วนใดส่วนหนึ่งโดยไม่ลบสิ่งที่คุณเขียนไว้:

| ส่วน | คืออะไร |
| --- | --- |
| **ส่วนหัว** | หัวข้อหลัก คำโปรย รูปแบนเนอร์ |
| **ความน่าเชื่อถือ** | สามจุดเด่น: ไม่มีค่าธรรมเนียม / ราคาดีที่สุด / ติดต่อโดยตรง |
| **รายการที่พัก** | การ์ดที่พักและห้องของคุณ มีเสมอ |
| **เกี่ยวกับ** | ข้อความอิสระและรูปภาพ (ไม่บังคับ) |
| **รีวิว** | คะแนนดาวที่ดึงมาจากช่องทางที่ซิงค์ไว้ |
| **แกลเลอรี** | ตารางรูปภาพของคุณเอง |
| **คำถามที่พบบ่อย** | คำถามที่แขกถามก่อนจอง |
| **บล็อก** | การ์ดตัวอย่างที่ลิงก์ไปยังบทความของคุณ |
| **ติดต่อ** | ข้อมูลติดต่อของคุณและแบบฟอร์มสอบถาม |
| **CTA** | แบนเนอร์ปิดท้ายพร้อมปุ่ม |
| **ข้อความอิสระ** | อะไรก็ได้ ตรงไหนก็ได้บนหน้า |

## 4. เลือกที่พักที่จะแสดง

เลือกที่พักบนเว็บไซต์ และวิธีที่แขกจองแต่ละแห่ง — จองได้ทันที หรือส่งคำขอ

## 5. เชื่อมต่อ Stripe

**การชำระเงิน** เชื่อมต่อบัญชี Stripe ของคุณเอง คุณเข้าสู่ระบบ (หรือสร้าง) Stripe บนเว็บไซต์ของ Stripe เอง
Santara AI ไม่เคยแตะเงินและไม่เคยเห็นหมายเลขบัตร

Santara AI เก็บ **ค่าคอมมิชชัน 3%** จากการจองตรง การชำระเงินเข้าบัญชี Stripe ของคุณเอง

## 6. เผยแพร่

ก่อนเผยแพร่ เว็บไซต์จะห้ามโปรแกรมรวบรวมข้อมูล (crawler) ทั้งหมด — ไม่มีอะไรหลุดออกไปก่อนคุณพร้อม
การเผยแพร่จะสร้าง sitemap และกฎ robots และอัปเดตให้ตรงกับสิ่งที่คุณเผยแพร่ภายหลัง

## โดเมนของคุณเอง

เว็บไซต์อยู่ที่ซับโดเมนเสมอ หากต้องการใช้โดเมนของคุณเอง — เช่น `www.yourvilla.com` — เพิ่มระเบียน DNS
สองรายการจากการ์ด **โดเมนที่กำหนดเอง** แล้วกด **ยืนยัน** ระบบตั้งค่า HTTPS ให้อัตโนมัติ ขั้นตอนทีละขั้น:
[เชื่อมต่อโดเมนของคุณเอง](/th/setup/custom-domain/)

## หน้าและบทความบล็อก

เขียนบทความและหน้าเดี่ยวในตัวแก้ไขเนื้อหาด้วยบล็อก: ข้อความ รูปภาพ ตาราง (หนึ่งแถวต่อบรรทัด คั่นคอลัมน์
ด้วย `|`) เส้นแบ่ง ใช้ `<strong>`, `<em>` และลิงก์ภายในข้อความได้

**แบบร่างเป็นส่วนตัวจนกว่าคุณจะเผยแพร่** แต่ละหน้ามีสรุป SEO ของตัวเอง — เพิ่มไว้ ไม่เช่นนั้นเครื่องมือค้นหา
จะดึงอะไรก็ได้ที่หาเจอ

## ข้อมูลติดต่อ

แสดงในส่วนติดต่อและส่วนท้ายของเว็บไซต์ ที่อยู่ลิงก์ไปยังแผนที่ Santara AI ไม่ฝัง iframe แผนที่ที่คุณให้มา
เลือกภาษาที่แขกเห็นเป็นภาษาแรก — แขกยังสลับภาษาได้

## สิ่งที่แขกได้รับ

เว็บไซต์ที่แสดงห้องของคุณพร้อมห้องว่างและราคาแบบสดจากปฏิทินเดียวกับที่ช่องทางใช้ การจองตรงจะปิดคืน
เหล่านั้นในทุกที่ เหมือนการจองจากช่องทาง

สิ่งที่แขกส่งกลับมาหาคุณ — คำถามจากแบบฟอร์มติดต่อ และคำขอจองสำหรับที่พักที่ใช้โหมดคำขอ — อยู่ที่
**[คำถามและคำขอจอง](/th/setup/booking-site-requests/)**
