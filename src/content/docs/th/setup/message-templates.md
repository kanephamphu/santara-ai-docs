**การตั้งค่า → เทมเพลตข้อความ** เทมเพลตคือคำตอบที่คุณส่งบ่อย พร้อม **ตัวแปร** ที่เติมค่าเองจาก
การเข้าพัก — ประโยค "รหัสประตูของคุณคือ 4417" จึงพิมพ์ครั้งเดียว ไม่ใช่สี่ร้อยครั้ง

เทมเพลต **อยู่ในขอบเขตของพื้นที่ทำงาน** คำตอบที่ทีมตกลงกันไว้จึงเป็นคำตอบที่ทุกคนส่ง

![เทมเพลตข้อความ พร้อมตัวแปรที่เติมค่าเองจากการเข้าพัก](/screens/message-templates.th.png)

## ตัวแปร

เขียนตัวยึดตำแหน่งในวงเล็บปีกกา แล้วค่าจะถูกเติมเมื่อใช้เทมเพลต:

```
Hi {guest_name}, we're excited to welcome you to {property_name}.
Check-in starts at {check_in_time}. Your door code is {door_code}.
```

ค่าที่ใช้ได้มาจากแขก การจองของแขก และที่พักที่อยู่เบื้องหลัง — ชื่อ ที่พัก เวลาเช็คอินและเช็คเอาท์
รหัสประตู wifi ยอดที่ต้องชำระ

**ตัวแปรดีได้เท่ากับที่พักที่อยู่เบื้องหลังเท่านั้น** `{door_code}` บนที่พักที่ไม่ได้บันทึกรหัสประตูไว้
จะไม่ได้อะไรที่มีประโยชน์ นี่เป็นอีกเหตุผลหนึ่งที่ควรกรอก
[ข้อมูลการเข้าพัก](/th/setup/properties/#ข้อมูลการเข้าพัก-wifi-รหัสประตู-การเข้าที่พัก)

## ดูตัวอย่างกับการเข้าพักจริง

เลือกการจอง ที่พัก หรือแขกที่มีอยู่จริงเป็น **บริบท** ระหว่างเขียน แล้วตัวอย่างจะเติมด้วยค่าจริงใน
พื้นที่ทำงานแทนตัวยึดตำแหน่ง นี่คือความต่างระหว่างเทมเพลตที่ดูเหมือนถูก กับเทมเพลตที่คุณเห็น
มันสร้างประโยคออกมาจริงแล้ว

## ใช้เทมเพลตที่ไหนบ้าง

- **ใน [ข้อความ](/th/daily/messages/)** — แทรกลงในเธรดใดก็ได้ และแก้ไขก่อนส่ง
- **ในร่างข้อความจาก AI** — คำตอบที่ผู้ช่วยแนะนำอิงจากเทมเพลตของคุณ สำนวนจึงยังเป็นของคุณ
  แทนที่จะกลับไปเป็นน้ำเสียงทั่วไป

ไม่มีอะไรถูกส่งอัตโนมัติ เทมเพลตเติมข้อความลงในช่อง คุณเป็นคนกดส่ง

## เทมเพลตที่มีให้ตั้งแต่เริ่มต้น

พื้นที่ทำงานใหม่ได้เทมเพลตห้าแบบ ครอบคลุมสิ่งที่แทบทุกคนต้องเขียนอยู่แล้ว:

| เทมเพลต | เมื่อไร |
| --- | --- |
| **ต้อนรับ / การมาถึง** | ก่อนเช็คอิน: เวลา รหัสประตู วิธีเข้าที่พัก |
| **แจ้งเตือนเช็คเอาท์** | วันก่อนหน้า: เวลา กุญแจ สิ่งที่ต้องทิ้งไว้ |
| **ข้อเสนอเช็คเอาท์ล่าช้า** | เมื่อปฏิทินเอื้ออำนวย — ดู [บริการเสริม](/th/money/upsells/) |
| **ขอรีวิว** | หลังการเข้าพักที่ดี |
| **ขออภัย** | เมื่อมีบางอย่างผิดพลาดและคุณต้องการเวลาอย่างตรงไปตรงมา |

แก้ไขได้ตามสบาย — การเปลี่ยนแปลงมีผลกับเทมเพลตที่บันทึกนั้นเท่านั้น และค่าเริ่มต้นเป็นเพียงจุดตั้งต้น
ไม่ใช่สิ่งที่ผลิตภัณฑ์คอยอัปเดตให้ตรงกันตลอด

## เขียนแยกตามภาษา

เทมเพลตเป็นข้อความ พื้นที่ทำงานที่รับแขกสามภาษาจึงต้องมีสามชุด ตั้งชื่อให้เห็นภาษาชัดเจนในรายการ
ไม่มีการแปลอัตโนมัติ และคำขอโทษที่แปลด้วยเครื่องแย่กว่าคำขอโทษสั้นๆ เป็นภาษาอังกฤษ
