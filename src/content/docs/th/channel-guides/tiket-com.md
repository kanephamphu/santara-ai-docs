วิธีเชื่อมต่อ Tiket.com กับ Santara AI ขั้นตอนใน Santara AI เหมือนกันทุกช่องทาง ([เชื่อมต่อช่องทางอื่น](/th/channels/other-channels/)) หน้านี้อธิบายเฉพาะสิ่งที่เป็นของ Tiket.com

## ก่อนเริ่มต้น

- **ที่พักที่มีห้องพักอย่างน้อยหนึ่งห้อง** ใน Santara AI
- **ไม่มีระบบจัดการช่องทางอื่นหรือลิงก์ iCal** บนที่พักใน Tiket.com — สองระบบที่อัปเดตปฏิทินเดียวกันจะเขียนทับกัน

## 1. เปิดการเชื่อมต่อใน Tiket.com

Tiket.com ต้องอนุญาตการเชื่อมต่อก่อน Channex คือพาร์ทเนอร์การเชื่อมต่อของ Santara AI — เป็นชื่อที่ Tiket.com รู้จักเรา

1. ส่งอีเมลถึงฝ่ายสนับสนุนของ Tiket.com เพื่อขอการเชื่อมต่อ **Channex**
2. จด **Hotel ID ของ Tiket.com** ของคุณไว้

ถ้ายังไม่มีระบบจัดการช่องทางใดเชื่อมต่ออยู่ คุณเลือก Channex เองใน extranet ได้

![extranet ของ Tiket.com: Connectivity แสดงระบบจัดการช่องทางที่เชื่อมต่ออยู่และ Hotel ID ของคุณ](/channel-guides/extranet/tiket-com-connectivity.webp)

## 2. เชื่อมต่อใน Santara AI

1. เปิด **การตั้งค่า → ช่องทาง → เพิ่มช่องทาง** ค้นหา **Tiket.com** แล้วกด **เชื่อมต่อ**
2. เลือกที่พักที่จะเชื่อมต่อ
3. กรอกช่องด้านล่าง แล้วกด **ทดสอบการเชื่อมต่อ**
4. เมื่อทดสอบผ่าน กด **เชื่อมต่อและดำเนินการต่อ**

![ขั้นตอนที่ 2 ใน Santara AI: ช่องตั้งค่าของ Tiket.com แล้วกดทดสอบการเชื่อมต่อ](/screens/channel-guides/tiket-com.th.png)

| ช่อง | สิ่งที่ต้องกรอก |
| --- | --- |
| Hotel ID | Hotel ID ของคุณใน Tiket.com |
| ส่งการแจ้งเตือนถึงที่พัก | ไม่บังคับ ติ๊กแล้วจะมีช่อง **อีเมลที่พัก** ปรากฏขึ้น — อีเมลนั้นจะได้รับอีเมลทุกครั้งที่มีการจองใหม่ |
| ประเภทจำนวนคืนขั้นต่ำ | จำนวนคืนขั้นต่ำแบบที่คุณส่ง: **วันเข้าพัก** หรือ **ถึง** ส่วนใหญ่ใช้วันเข้าพัก |

หาก**ทดสอบการเชื่อมต่อ**ไม่ผ่าน ให้ตรวจสอบ ID แล้วขอให้ฝ่ายสนับสนุนของ Tiket.com ยืนยันว่าที่พักเชื่อมต่อกับ Channex แล้ว

## 3. จับคู่ห้องพักและราคา

- จับคู่ห้องพักแต่ละห้องของช่องทางกับห้องพักของคุณ และจับคู่แต่ละราคาของช่องทางกับแผนราคาหนึ่งของคุณ

จับคู่ **ทุก** ห้องพักและราคาที่ Tiket.com แสดง รายการที่ไม่ได้จับคู่จะไม่ได้รับการอัปเดต และ Tiket.com จะขายต่อไปตามห้องว่างเดิม

## 4. นำเข้าและเปิดขาย

Santara AI ตรวจสอบสิ่งที่จับคู่ไว้ เปิดใช้ช่องทาง และนำการเข้าพักที่ Tiket.com มีอยู่แล้วเข้ามา จากนั้นราคา ห้องว่าง และข้อจำกัดจะซิงค์จาก Santara AI — ดู [การเปิดขาย](/th/channels/going-live/)

## ข้อควรรู้

- ตอบแขกของ Tiket.com ในกล่องข้อความของ Tiket.com เอง — ข้อความจากแขกของ Tiket.com ไม่เข้ามาใน Santara AI
