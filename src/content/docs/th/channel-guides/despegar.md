วิธีเชื่อมต่อ Despegar กับ Santara AI ขั้นตอนใน Santara AI เหมือนกันทุกช่องทาง ([เชื่อมต่อช่องทางอื่น](/th/channels/other-channels/)) หน้านี้อธิบายเฉพาะสิ่งที่เป็นของ Despegar

## ก่อนเริ่มต้น

- **ที่พักที่มีห้องพักอย่างน้อยหนึ่งห้อง**ใน Santara AI
- **ไม่มีระบบจัดการช่องทางอื่นหรือลิงก์ iCal** บนที่พักใน Despegar — สองระบบที่อัปเดตปฏิทินเดียวกันจะเขียนทับกัน

## 1. เปิดการเชื่อมต่อใน Despegar

Despegar ต้องอนุญาตการเชื่อมต่อก่อน Channex คือพาร์ทเนอร์การเชื่อมต่อของ Santara AI — เป็นชื่อที่ Despegar รู้จักเรา

1. ใน extranet ของ Despegar เปิด **General Settings → Channel Manager Connection**
2. **ปิดหรือลบ** การเชื่อมต่อระบบจัดการช่องทางเดิมทั้งหมด
3. กด **Add channel manager / PMS** เลือก **Channex** แล้วยอมรับข้อกำหนด
4. คัดลอก **property ID** **username** และ **API password** ที่ Despegar แสดง

![การเชื่อมต่อระบบจัดการช่องทางใน Despegar — ปิดหรือลบรายการเดิม](/channel-guides/extranet/despegar-connections.webp)

![การเลือกระบบจัดการช่องทางใน Despegar และยอมรับข้อกำหนด](/channel-guides/extranet/despegar-add.webp)

:::danger[คัดลอกรหัสผ่าน API ตอนนี้เลย]
Despegar แสดงรหัสผ่าน API เพียงครั้งเดียว หากทำหาย ให้รีเซ็ตการเชื่อมต่อใน Despegar เพื่อรับรหัสใหม่ รหัสผ่าน extranet ปกติของคุณใช้ที่นี่ไม่ได้
:::

## 2. เชื่อมต่อใน Santara AI

1. เปิด **การตั้งค่า → ช่องทาง → เพิ่มช่องทาง** ค้นหา **Despegar** แล้วกด **เชื่อมต่อ**
2. เลือกที่พักที่จะเชื่อมต่อ
3. กรอกช่องด้านล่าง แล้วกด **ทดสอบการเชื่อมต่อ**
4. เมื่อทดสอบผ่าน กด **เชื่อมต่อและดำเนินการต่อ**

| ช่อง | สิ่งที่ต้องกรอก |
| --- | --- |
| Hotel ID | property ID ของ Despegar |
| ชื่อผู้ใช้ | username ที่ Despegar แสดง |
| รหัสผ่าน | **API password** — ไม่ใช่รหัสผ่าน extranet ของคุณ |
| ประเภทจำนวนคืนขั้นต่ำ | Despegar รับได้แบบเดียว เลือกแบบที่จะส่ง |

หาก**ทดสอบการเชื่อมต่อ**ไม่ผ่าน ให้ตรวจสอบ ID แล้วขอให้ฝ่ายสนับสนุนของ Despegar ยืนยันว่าที่พักเชื่อมต่อกับ Channex แล้ว

## 3. จับคู่ห้องพักและราคา

- จับคู่ห้องพักแต่ละห้องของช่องทางกับห้องพักของคุณ และจับคู่แต่ละราคาของช่องทางกับแผนราคาหนึ่งของคุณ
- ราคาสำหรับ 1 คนบนห้องดับเบิลใช้ได้ — Despegar ตั้งราคาผู้เข้าพักเพิ่มเติมใน extranet ได้

จับคู่**ทุก**ห้องพักและราคาที่ Despegar แสดง รายการที่ไม่ได้จับคู่จะไม่ได้รับการอัปเดต และ Despegar จะขายต่อไปตามห้องว่างเดิม

## 4. นำเข้าและเปิดขาย

Santara AI ตรวจสอบสิ่งที่จับคู่ไว้ เปิดใช้ช่องทาง และนำการเข้าพักที่ Despegar มีอยู่แล้วเข้ามา จากนั้นราคา ห้องว่าง และข้อจำกัดจะซิงค์จาก Santara AI — ดู [การเปิดขาย](/th/channels/going-live/)

## ข้อควรรู้

- ตอบแขกของ Despegar ในกล่องข้อความของ Despegar เอง — ข้อความจากแขกของ Despegar ไม่เข้ามาใน Santara AI
