วิธีเชื่อมต่อ Hopper Homes กับ Santara AI ขั้นตอนใน Santara AI เหมือนกันทุกช่องทาง ([เชื่อมต่อช่องทางอื่น](/th/channels/other-channels/)) หน้านี้อธิบายเฉพาะสิ่งที่เป็นของ Hopper Homes

## ก่อนเริ่มต้น

- ราคาและการจองบน Hopper Homes เป็น **USD** — ราคาของคุณจะถูกแปลงสกุลเงินให้อัตโนมัติ
- ใช้**อีเมลเดียวกัน**สำหรับ Hopper และสำหรับการเชื่อมต่อนี้
- **ที่พักที่มีห้องพักอย่างน้อยหนึ่งห้อง**ใน Santara AI
- **ไม่มีระบบจัดการช่องทางอื่นหรือลิงก์ iCal** บนที่พักใน Hopper Homes — สองระบบที่อัปเดตปฏิทินเดียวกันจะเขียนทับกัน

## 1. เปิดการเชื่อมต่อใน Hopper Homes

Hopper Homes ต้องอนุญาตการเชื่อมต่อก่อน Channex คือพาร์ทเนอร์การเชื่อมต่อของ Santara AI — เป็นชื่อที่ Hopper Homes รู้จักเรา

1. สมัครบัญชี Hopper Hosting ที่ **hosts.hopper.com/signup/channex**
2. เปิดอีเมลจาก Hopper Homes แล้วกด **Join Hopper Hosting** เพื่อตั้งรหัสผ่าน
3. เมื่อถูกถามว่าคุณใช้ PMS หรือไม่ ให้เลือก **Yes** แล้วเลือก **Channex**

## 2. เชื่อมต่อใน Santara AI

1. เปิด **การตั้งค่า → ช่องทาง → เพิ่มช่องทาง** ค้นหา **Hopper Homes** แล้วกด **เชื่อมต่อ**
2. เลือกที่พักที่จะเชื่อมต่อ
3. กรอกช่องด้านล่าง แล้วกด **ทดสอบการเชื่อมต่อ**
4. เมื่อทดสอบผ่าน กด **เชื่อมต่อและดำเนินการต่อ**

| ช่อง | สิ่งที่ต้องกรอก |
| --- | --- |
| อีเมลโฮสต์ที่ยืนยันแล้ว | อีเมลที่คุณใช้สมัคร Hopper |
| ชื่อโฮสต์ที่แสดง | ชื่อโฮสต์ที่แขกเห็น |
| ประเภทจำนวนคืนขั้นต่ำ | **วันเข้าพัก** หรือ **ถึง** ส่วนใหญ่ใช้วันเข้าพัก |
| ส่งการแจ้งเตือนถึงที่พัก | ไม่บังคับ ติ๊กแล้วจะมีช่อง **อีเมลที่พัก** ปรากฏขึ้น — อีเมลนั้นจะได้รับอีเมลทุกครั้งที่มีการจองใหม่ |

หาก**ทดสอบการเชื่อมต่อ**ไม่ผ่าน ให้ตรวจสอบ ID แล้วขอให้ฝ่ายสนับสนุนของ Hopper Homes ยืนยันว่าที่พักเชื่อมต่อกับ Channex แล้ว

## 3. จับคู่ห้องพักและราคา

- รายการที่พักของ Hopper Homes **สร้างจากหน้าตั้งค่า**: สร้างรายการที่พักสำหรับแต่ละห้อง เลือกที่พักและห้องพัก กรอกรายละเอียด แล้วบันทึก
- **เปิดใช้งาน**รายการที่พัก แล้วจับคู่กับห้องพักและราคาของคุณในหน้าจับคู่

จับคู่**ทุก**ห้องพักและราคาที่ Hopper Homes แสดง รายการที่ไม่ได้จับคู่จะไม่ได้รับการอัปเดต และ Hopper Homes จะขายต่อไปตามห้องว่างเดิม

## 4. นำเข้าและเปิดขาย

Santara AI ตรวจสอบสิ่งที่จับคู่ไว้ เปิดใช้ช่องทาง และนำการเข้าพักที่ Hopper Homes มีอยู่แล้วเข้ามา จากนั้นราคา ห้องว่าง และข้อจำกัดจะซิงค์จาก Santara AI — ดู [การเปิดขาย](/th/channels/going-live/)

:::caution[อย่าลบการเชื่อมต่อ]
Hopper Homes ไม่อนุญาตให้บัญชีเชื่อมต่อใหม่ หากคุณลบการเชื่อมต่อนี้ คุณจะต้องใช้บัญชี Hopper ใหม่ด้วยอีเมลอื่น
:::
