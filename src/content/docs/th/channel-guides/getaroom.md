วิธีเชื่อมต่อ Getaroom กับ Santara AI ขั้นตอนใน Santara AI เหมือนกันทุกช่องทาง ([เชื่อมต่อช่องทางอื่น](/th/channels/other-channels/)) หน้านี้อธิบายเฉพาะสิ่งที่เป็นของ Getaroom

## ก่อนเริ่มต้น

- **ที่พักที่มีห้องพักอย่างน้อยหนึ่งห้อง**ใน Santara AI
- **ไม่มีระบบจัดการช่องทางอื่นหรือลิงก์ iCal** บนที่พักใน Getaroom — สองระบบที่อัปเดตปฏิทินเดียวกันจะเขียนทับกัน

## 1. เปิดการเชื่อมต่อใน Getaroom

Getaroom ต้องอนุญาตการเชื่อมต่อก่อน Channex คือพาร์ทเนอร์การเชื่อมต่อของ Santara AI — เป็นชื่อที่ Getaroom รู้จักเรา

1. ส่งอีเมลถึง propertyactivation@getaroom.com เพื่อขอการเชื่อมต่อกับ **Channex** พร้อมแจ้ง Hotel ID ของคุณ
2. Getaroom จะตอบกลับพร้อม Hotel ID ที่ต้องใช้

## 2. เชื่อมต่อใน Santara AI

1. เปิด **การตั้งค่า → ช่องทาง → เพิ่มช่องทาง** ค้นหา **Getaroom** แล้วกด **เชื่อมต่อ**
2. เลือกที่พักที่จะเชื่อมต่อ
3. กรอกช่องด้านล่าง แล้วกด **ทดสอบการเชื่อมต่อ**
4. เมื่อทดสอบผ่าน กด **เชื่อมต่อและดำเนินการต่อ**

| ช่อง | สิ่งที่ต้องกรอก |
| --- | --- |
| Hotel ID | Hotel ID ที่ Getaroom ยืนยันมา |

หาก**ทดสอบการเชื่อมต่อ**ไม่ผ่าน ให้ตรวจสอบ ID แล้วขอให้ฝ่ายสนับสนุนของ Getaroom ยืนยันว่าที่พักเชื่อมต่อกับ Channex แล้ว

## 3. จับคู่ห้องพักและราคา

- จับคู่ห้องพักแต่ละห้องของช่องทางกับห้องพักของคุณ และจับคู่แต่ละราคาของช่องทางกับแผนราคาหนึ่งของคุณ
- จากนั้นแจ้ง Getaroom ว่าจับคู่เสร็จแล้ว

จับคู่**ทุก**ห้องพักและราคาที่ Getaroom แสดง รายการที่ไม่ได้จับคู่จะไม่ได้รับการอัปเดต และ Getaroom จะขายต่อไปตามห้องว่างเดิม

## 4. นำเข้าและเปิดขาย

Santara AI ตรวจสอบสิ่งที่จับคู่ไว้ เปิดใช้ช่องทาง และนำการเข้าพักที่ Getaroom มีอยู่แล้วเข้ามา จากนั้นราคา ห้องว่าง และข้อจำกัดจะซิงค์จาก Santara AI — ดู [การเปิดขาย](/th/channels/going-live/)

## ข้อควรรู้

- Getaroom จะส่ง**การจองและการยกเลิกทดสอบ**เพื่อตรวจสอบการเชื่อมต่อ หลังจากนั้นที่พักจะเปิดขาย
- ตอบแขกของ Getaroom ในกล่องข้อความของ Getaroom เอง — ข้อความจากแขกของ Getaroom ไม่เข้ามาใน Santara AI
