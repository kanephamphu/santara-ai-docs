วิธีเชื่อมต่อ Inntopia กับ Santara AI ขั้นตอนใน Santara AI เหมือนกันทุกช่องทาง ([เชื่อมต่อช่องทางอื่น](/th/channels/other-channels/)) หน้านี้อธิบายเฉพาะสิ่งที่เป็นของ Inntopia

## ก่อนเริ่มต้น

- คุณต้องมี **สัญญาของคุณเอง** กับ Inntopia โดยมีรายละเอียดและรูปภาพของที่พักอยู่ใน extranet ของ Inntopia แล้ว Santara AI เชื่อมต่อที่พักที่สมัครไว้แล้ว แต่สร้างที่พักบน Inntopia แทนคุณไม่ได้
- **ที่พักที่มีห้องพักอย่างน้อยหนึ่งห้อง** ใน Santara AI
- **ไม่มีระบบจัดการช่องทางอื่นหรือลิงก์ iCal** บนที่พักใน Inntopia — สองระบบที่อัปเดตปฏิทินเดียวกันจะเขียนทับกัน

## 1. เปิดการเชื่อมต่อใน Inntopia

Inntopia ต้องอนุญาตการเชื่อมต่อก่อน Channex คือพาร์ทเนอร์การเชื่อมต่อของ Santara AI — เป็นชื่อที่ Inntopia รู้จักเรา

1. ลงชื่อเข้าใช้ Inntopia แล้วเปิดแท็บ **Products**
2. ที่แต่ละผลิตภัณฑ์ กดปุ่มการตั้งค่าทางขวา แล้วเลือก **Cross-reference codes**
3. ตั้ง **Remote system** เป็น **Channex**
4. ตั้ง **Cross-reference code** เป็น product ID ของ Inntopia — ตัวเลขในวงเล็บในชื่อผลิตภัณฑ์
5. บันทึกด้วยช่องเครื่องหมายถูกสีน้ำเงิน ปิด แล้วทำซ้ำกับผลิตภัณฑ์ถัดไป

![cross-reference code ของ Inntopia: Remote System เป็น Channex และรหัส = product ID ในวงเล็บ](/channel-guides/extranet/inntopia-cross-reference.webp)

## 2. เชื่อมต่อใน Santara AI

1. เปิด **การตั้งค่า → ช่องทาง → เพิ่มช่องทาง** ค้นหา **Inntopia** แล้วกด **เชื่อมต่อ**
2. เลือกที่พักที่จะเชื่อมต่อ
3. กรอกช่องด้านล่าง แล้วกด **ทดสอบการเชื่อมต่อ**
4. เมื่อทดสอบผ่าน กด **เชื่อมต่อและดำเนินการต่อ**

| ช่อง | สิ่งที่ต้องกรอก |
| --- | --- |
| Hotel ID | Hotel ID ของคุณใน Inntopia |

หาก**ทดสอบการเชื่อมต่อ**ไม่ผ่าน ให้ตรวจสอบ ID แล้วขอให้ฝ่ายสนับสนุนของ Inntopia ยืนยันว่าที่พักเชื่อมต่อกับ Channex แล้ว

## 3. จับคู่ห้องพักและราคา

- **ต่อห้องพัก** — ราคาเดียวสำหรับห้อง ไม่ว่าใครเข้าพัก จับคู่ราคาสำหรับจำนวนผู้เข้าพักเต็มห้อง
- จับคู่เฉพาะราคา **RACK**

จับคู่ **ทุก** ห้องพักและราคาที่ Inntopia แสดง รายการที่ไม่ได้จับคู่จะไม่ได้รับการอัปเดต และ Inntopia จะขายต่อไปตามห้องว่างเดิม

## 4. นำเข้าและเปิดขาย

Santara AI ตรวจสอบสิ่งที่จับคู่ไว้ เปิดใช้ช่องทาง และนำการเข้าพักที่ Inntopia มีอยู่แล้วเข้ามา จากนั้นราคา ห้องว่าง และข้อจำกัดจะซิงค์จาก Santara AI — ดู [การเปิดขาย](/th/channels/going-live/)

## ข้อควรรู้
