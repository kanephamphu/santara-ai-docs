วิธีเชื่อมต่อ Agoda กับ Santara AI ขั้นตอนใน Santara AI เหมือนกันทุกช่องทาง ([เชื่อมต่อช่องทางอื่น](/th/channels/other-channels/)) หน้านี้อธิบายเฉพาะสิ่งที่เป็นของ Agoda

## ก่อนเริ่มต้น

- คุณต้องมี**สัญญาของคุณเอง**กับ Agoda โดยมีรายละเอียดและรูปภาพของที่พักอยู่ใน extranet ของ Agoda แล้ว Santara AI เชื่อมต่อที่พักที่สมัครไว้แล้ว แต่สร้างที่พักบน Agoda แทนคุณไม่ได้
- **ที่พักที่มีห้องพักอย่างน้อยหนึ่งห้อง**ใน Santara AI
- **ไม่มีระบบจัดการช่องทางอื่นหรือลิงก์ iCal** บนที่พักใน Agoda — สองระบบที่อัปเดตปฏิทินเดียวกันจะเขียนทับกัน

## 1. เปิดการเชื่อมต่อใน Agoda

Agoda ต้องอนุญาตการเชื่อมต่อก่อน Channex คือพาร์ทเนอร์การเชื่อมต่อของ Santara AI — เป็นชื่อที่ Agoda รู้จักเรา

1. ใน Agoda **YCS** เปิด **Settings → Property Settings → Optional Settings**
2. ติ๊ก **Enable channel manager mode**
3. เลือก **Channex** จากรายการ แล้วกด **Save**

หรือขอให้ฝ่ายสนับสนุนของ Agoda เชื่อมต่อ Channex ให้ ผ่านระบบข้อความใน extranet

![Agoda YCS: Settings → Property Settings → Optional settings โดยติ๊ก Enable channel manager mode และเลือกผู้ให้บริการแล้ว](/channel-guides/extranet/agoda-ycs.webp)

## 2. เชื่อมต่อใน Santara AI

1. เปิด **การตั้งค่า → ช่องทาง → เพิ่มช่องทาง** ค้นหา **Agoda** แล้วกด **เชื่อมต่อ**
2. เลือกที่พักที่จะเชื่อมต่อ
3. กรอกช่องด้านล่าง แล้วกด **ทดสอบการเชื่อมต่อ**
4. เมื่อทดสอบผ่าน กด **เชื่อมต่อและดำเนินการต่อ**

![ขั้นตอนที่ 2 ใน Santara AI: ช่องตั้งค่าของ Agoda แล้วกดทดสอบการเชื่อมต่อ](/screens/channel-guides/agoda.th.png)

| ช่อง | สิ่งที่ต้องกรอก |
| --- | --- |
| Hotel ID | Hotel ID ของคุณใน Agoda |
| ส่งการแจ้งเตือนถึงที่พัก | ไม่บังคับ ติ๊กแล้วจะมีช่อง **อีเมลที่พัก** ปรากฏขึ้น — อีเมลนั้นจะได้รับอีเมลทุกครั้งที่มีการจองใหม่ |
| การตั้งค่าภาษีสำหรับการจอง | **รวม** — รวมภาษีแล้ว หักค่าคอมมิชชันแล้ว (ยอดที่คุณได้รับ) **Inclusive With Commissions** — รวมทั้งภาษีและค่าคอมมิชชัน (ยอดที่แขกจ่าย) **ไม่รวม** — ไม่รวมภาษีและค่าคอมมิชชัน (แบบสหรัฐอเมริกา) |

หาก**ทดสอบการเชื่อมต่อ**ไม่ผ่าน ให้ตรวจสอบ ID แล้วขอให้ฝ่ายสนับสนุนของ Agoda ยืนยันว่าที่พักเชื่อมต่อกับ Channex แล้ว

## 3. จับคู่ห้องพักและราคา

- **ราคาตามจำนวนผู้เข้าพัก** — หนึ่งราคาต่อจำนวนผู้เข้าพักแต่ละแบบ หากห้องมีราคาเดียว ให้จับคู่ราคาเดียวกันนั้นกับทุกจำนวนผู้เข้าพัก

จับคู่**ทุก**ห้องพักและราคาที่ Agoda แสดง รายการที่ไม่ได้จับคู่จะไม่ได้รับการอัปเดต และ Agoda จะขายต่อไปตามห้องว่างเดิม

## 4. นำเข้าและเปิดขาย

Santara AI ตรวจสอบสิ่งที่จับคู่ไว้ เปิดใช้ช่องทาง และนำการเข้าพักที่ Agoda มีอยู่แล้วเข้ามา จากนั้นราคา ห้องว่าง และข้อจำกัดจะซิงค์จาก Santara AI — ดู [การเปิดขาย](/th/channels/going-live/)

## ข้อควรรู้

- ตอบแขกของ Agoda ในกล่องข้อความของ Agoda เอง — ข้อความจากแขกของ Agoda ไม่เข้ามาใน Santara AI
